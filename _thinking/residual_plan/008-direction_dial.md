## 5. ⭐ 진짜 눈금을 이미 쥐고 있었다 — 잔차 코사인 = A-1/A-2 판별기

[문서] 018 §9-d 는 노선의 성패를 **두 실패 모드 중 어디에 떨어지느냐**로 못 박고, 그 칸을 비워 뒀다.

```
A-1  방향이 섞임        → 어떤 해상도·세기로도 static 에 진다.  해상도를 올리면 **더 나빠진다**
A-2  방향 맞고 세기만 약함 → 세기 25% 만 맞혀도 이긴다.  해상도를 올리면 좋아진다
018 의 결론:  "둘을 화해시키는 유일한 길은 실제로 학습해 보는 것이다"
```

**그런데 잔차 코사인이 바로 그 판별기다. 아무도 눈치채지 못했다.**

```
A-2 는 출력 = α × 정답잔차 다.  코사인은 **크기에 불변**이므로 α 가 얼마든 코사인 = 정확히 1.0
A-1 은 출력 = α × 정답잔차 + (1−α) × 남의잔차.  코사인 = α / √(α²+(1−α)²)  < 1
```

| 우리 출력의 성격 | 잔차 코사인 | k=2 에서 static 대비 (018 §9-d) |
|---|---:|---:|
| **A-2** (방향 맞고 약함), α 무관 | **1.00** | α=0.25 에서 **−0.008 이득** |
| A-1 α=0.75 | 0.95 | −0.000 본전 |
| A-1 α=0.50 | 0.71 | +0.018 손해 |
| A-1 α=0.35 | 0.47 | +0.026 손해 |
| A-1 α=0.25 | 0.32 | +0.031 손해 |
| **오늘 탐침 실측 (1500스텝)** | **0.12** | (외삽) **+0.036 손해** |

**확정인 것 [문서+산술]**: A-2 면 코사인이 **정확히 1.0** 이어야 한다. 우리는 0.12 다.
**⇒ 지금 이 탐침의 출력은 A-2 가 아니다.** 018 이 걸었던 희망 —
*"결정론 회귀는 조건부 평균이라 방향을 안 흔들고 세기만 줄인다 = A-2 쪽"* — 은 **이 작동점에서 성립하지 않는다.**

⚠ **[추측]인 것**: 마지막 줄의 손해 외삽. A-1 의 "틀린 성분"은 *남의 잔차*이고,
회귀기의 틀린 성분은 *흐릿한 평균*이라 같은 물건이 아니다. 018 §9-d F 가 20.52% 민감도를 경고했다.
⚠ **미지인 것**: 1500스텝 hid_S=16 탐침은 수렴한 모델이 아니다. **0.12 는 하한이지 천장이 아니다.**

## 9. ⭐ 그래서 내일(8/9) 뭘 하나 — 이 절만 봐도 된다

### 9-a. 제출은 산출물이 아니라 **측정 장비**다 — 006 §1-③ 을 부분 정정한다

006 은 *"얇고 빠른 v1 보다 제대로 된 한 번이 낫다"* 고 했다. **최종 산출물에는 맞고, 계기에는 틀렸다.**

```
최종 채점은 팀이 고른 파일 1개.  중간 제출은 몇 개가 나쁘든 **비용이 0** 이다
남은 제출 130회.  쓴 횟수 0회.  하루 10회는 이월되지 않는다 — 안 쓰면 그냥 사라진다
```

### 9-b. ⭐ **λ 스윕** — 노선 전체를 5회 제출로 판정한다

```
출력 = 첫 프레임 + λ × 예측잔차          λ 는 추론 때 곱하는 숫자 하나.  재학습 불필요
λ = 0 이면 정확히 정지영상 = S₀           ← 하방이 봉쇄된다
λ ∈ {0, 0.25, 0.5, 0.75, 1.0}  = 5회 = 반나절 몫
```

| 곡선 모양 | 뜻 | 다음 행동 |
|---|---|---|
| λ 커질수록 **좋아짐** | **A-2 다** | N_S=2 로 해상도를 올린다. 018 이 약속한 관대한 구간 |
| λ 커질수록 **나빠짐** | **A-1 이다** | 해상도를 올리면 더 나빠진다. 손실·구조를 바꾼다 |
| 중간에 최소 | 섞임 + 유용분 공존 | 그 λ 를 고정하고 계속 |

**이 한 번의 스윕이 로컬 프록시 열 개보다 정보가 많다.** 로컬→eval 이송 계수도 같이 나온다.
(⚠ 규칙 확인: λ 는 **우리 모델 출력에 곱하는 상수**다. 킷과 무관하다. §13 위반 아님.)

### 9-c. 순서

```
1  [사용자]  정지영상 재제출 → S₀ 회수     ✅ 8/8 오늘 나간다 (사용자 확정)
2  [GPU]    아래 9-d 에서 고른다
3  [구현]   본 학습 루프 = ProbeNet 을 hid_S=64·N_S=2·320×512 로.  손실 = L1 + 코사인
4  [제출]   첫 체크포인트가 나오는 즉시 λ 스윕 5회               (기다리지 마라)
```

⚠ **2 는 3 을 막지 않는다.** 로더(`loader_c.py`)와 모델(`ProbeNet`)은 이미 있다. **동시에 간다.**
