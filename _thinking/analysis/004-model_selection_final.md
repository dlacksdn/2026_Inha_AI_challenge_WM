## 1. 결론 요약

### 최종 선정

> **"Vid2World 채택"이라는 프레이밍은 폐기한다.**
> 최종 선정은 **모델이 아니라 아키텍처 계열 + 결정 절차**다:
>
> **[확정] 대회 베이스라인(challenge_kit)의 DynamiCrafter 계열 잠재 확산 구조를 유지하고,
> ① 액션 드롭아웃(`action_dropout_prob` 0 → 0.1)을 켜서 액션 CFG를 활성화하고,
> ② 백본 용량(현행 11M 유지 / 중형 100–400M 스크래치 / DynamiCrafter 1.1B 사전학습 승격)은
> 바닥값 3종 측정과 추론 실측이 끝난 뒤 분기 결정한다.**
> Vid2World는 "채택 모델"이 아니라 **액션 주입·CFG 레시피의 참고 문헌**으로 강등한다.

### 3줄 근거

1. **critic의 치명 지적 중 지표 특성(C1)과 "이미 구현됨"(C5)은 원출처·코드로 완전 재확인됐고, 예산 지적(C2·C4)은 방향은 옳으나 GPU 스펙 오독(C6)으로 정도가 과장돼 있었다.** 어느 쪽이든 "1.1B 채택"을 측정 없이 확정할 근거가 없으므로, 용량 결정은 측정 뒤로 미루는 것이 유일하게 정직한 결론이다.
2. **대안 전수 재조사에서도 DynamiCrafter 계열을 이기는 후보가 없었다.** LeRobot v0.6.0 신모델 포함 5종을 원출처로 검증한 결과 전부 하드 게이트(관절 액션·320×512·16f·예산)에서 탈락한다(§4).
3. **베이스라인에 액션 주입·드롭아웃·CFG 배선이 이미 있고, 주최측 노트북이 DynamiCrafter_512 가중치를 직접 다운로드한다.** 즉 "백본 승격 + CFG 활성화"는 이식이 아니라 **이미 승인된 계보 안에서의 설정·코드 확장**이며, 리스크가 가장 작은 경로다.

### 쟁점별 명시적 결론 (임무 지정 5개)

| 쟁점 | 결론 | 근거 위치 |
|---|---|---|
| DynamiCrafter 가중치 라이선스 | **부합 (수상 취소 리스크 낮음)** — 단 제출 시 문서화 + 사전 문의 권장 | §5.1 |

## 2. critic 지적 심판표

판정 기호: **수용**(critic이 옳음) / **부분**(방향은 옳으나 세부 오류·조건부) / **반박**(critic이 틀림) / **갱신**(critic의 "미확인"을 이번 검증으로 확정).
"검증"열의 `[로컬]`=패키지 코드 직독·재계산, `[웹]`=원출처 확인, `[계산]`=수치 재계산.

## 3. 심판 총평 — 누가 어디서 옳았나

- **critic의 치명·중대 지적은 대부분 유효했다.** 특히 채점 코드 실측(C1, M1)과 eval 분포 이탈(M2)은 이번 재계산에서 수치까지 완전 재현됐다.
- **1차 문서의 사실 수집도 대체로 정확했다**(critic 스스로 14개 항목 인정). 무너진 것은 사실이 아니라 **사실→결론의 추론**(용량 논거, 예산 ✅ 판정, "이식"이라는 표현)이다.
- **critic에도 실질적 오류가 있었다**: 가장 큰 것은 **GPU 배율 오독(C6)** — 예산 관련 두 치명 지적(C2·C4)의 수치가 절반 수준으로 과장돼 있었고, "추론 확정 초과"는 "경계선"으로 완화된다(결론의 방향 자체는 유지). 그 외 Cosmos 32.54GB의 출처 정정(m1)과 1.4B 표기 위치(m2)도 critic 쪽이 틀렸다. critic이 "미확인"으로 남긴 ICLR 승인(m3)과 uncond 분기의 액션 CFG 배선(C5의 추가 발견)은 이번 검증으로 확정했다.
- **양쪽 다 틀린 지점도 있었다**: critic §9는 "0.4×든 0.8×든 결론 불변"이라 적었지만, 추론 예산에서는 r ≥ 1.0이면 50스텝이 예산 안에 들어와 "이미 초과" 판정 자체가 흔들린다. 서사가 아니라 실측(M1)만이 이 논쟁을 끝낸다.
- 교훈(critic §10의 결론을 채택): **측정 없는 서사로 결론을 지지하지 않는다.** 이하 최종안은 모든 분기점을 측정 가능한 실험에 건다.

### 5.2 추론 예산 — 50스텝 기본값은 경계선, 50스텝+CFG는 초과. NFE ≤ 32–50으로 설계

**기준 실측치**(원출처): DynamiCrafter 320×512, A100, DDIM 50스텝, 배치 1 → **20 s/샘플, 12.8 GB** (VAE 디코드 포함).
즉 **0.4 s/NFE**가 1.1B급의 기준 단가다. (NFE = 스텝 수 × CFG 계수. CFG를 켜면 스텝당 UNet 2회.)

**예산식**: `소요시간(분) = 216 × NFE × 0.4 / (r × b) / 60`
— r = 대회 GPU(RTX PRO 6000 Blackwell)의 對A100 속도비, b = 배칭 이득(현실 1.2~2.0, C3 판정 반영).

**r의 값 (C6 반박 반영)**: critic의 0.4~0.8은 **FP32 셰이더 수치(125 TFLOPS)를 BF16 텐서 수치로 오독**한 비교 사이트에서 온 것이라 기각한다. NVIDIA 공식 페이지 기준 125 TFLOPS의 라벨은 "Single-Precision Performance"다. dense BF16 텐서 추정 250~500 TFLOPS(對A100 312 → 0.8~1.6), 추론 실측 벤치마크는 1.6~3.0× 우위. 계획은 **보수적으로 r = 0.8~1.3**을 쓰되(2차 자료 간 2배 불일치가 남아 있으므로), **최종 확정은 M1 실측**으로 한다.

| 구성 | NFE | r=0.8, b=1.5 | r=1.0, b=1.5 | r=1.3, b=1.5 | 판정 |
|---|---:|---:|---:|---:|---|
| 50스텝, CFG 없음 (베이스라인 기본) | 50 | 60분 | 48분 | 37분 | ⚠️ **경계선** — 마진 없이 턱걸이 |
| 50스텝 + 액션 CFG | 100 | 120분 | 96분 | 74분 | ❌ 명백 초과 |
| **25스텝 + 액션 CFG** | 50 | 60분 | 48분 | 37분 | ⚠️ 경계선 |
| **25스텝, CFG 없음** | 25 | 30분 | 24분 | 18분 | ✅ 여유 |
| **16스텝 + 액션 CFG** | 32 | 38분 | 31분 | 24분 | ✅ |

**확정 규칙**:
- 설계 상한 **NFE ≤ 32–50** (VAE 디코드·I/O 마진 10~15% 포함해 60분 목표의 ~80% 선. NFE 50은 r ≥ 1.0 실측 확인 시에만 허용).
- 액션 CFG를 쓰려면 스텝을 16~25로 줄인다. **저스텝에서의 품질 손실 vs CFG 이득**은 로컬 모의채점으로 비교 결정(§7 M5).
- 11M 백본을 유지하는 분기라면 예산이 수십 배 여유 — 이 경우 CFG·스텝 제약이 사실상 사라진다는 것도 분기 결정의 변수다.
- **0순위 실측**: 5090에서 1.1B UNet 스텝당 시간과 배치 스케일링을 재고, 대회 GPU 검증 기회가 생기는 즉시 r을 확정한다.

### 5.3 학습 예산 — 논문 스케일 불가, 두 가지 현실 구성

**불변량으로 확정**: Vid2World RT-1 post-training = 28 A100-day. 대회 예산 = 4일 × r(0.8~1.3, C6 보정) = **3.2~5.2 A100-day**. 격차 **5.4~8.8배** — critic의 추정(9~18배)보다 절반으로 줄었지만, r의 불확실성과 무관하게 "논문 스케일 재현 불가"라는 결론은 뒤집히지 않는다(C4).

**현실적 학습 구성 2안** (분기는 M0 측정 후):

| | 분기 A: 중형 스크래치 | 분기 B: DC 1.1B 부분 적응 |
|---|---|---|
| 백본 | 100–400M UNet (11M 설정의 `model_channels` 64~128로 확장) | DC 1.1B 설정 + backbone.ckpt UNet 가중치 로드 |
| 학습 대상 | 전체 (스크래치) | 액션 분기(스크래치) + 시간축 레이어 + LoRA(공간 어텐션), 나머지 동결 |
| 근거 | 채점 지표가 전부 저해상·전역이라(C1) 사전학습 프라이어의 이득이 미검증. 예산 내 수렴 가능한 유일한 대형화 경로 | 계보 호환(`in_channels 8`, `context_dim 1024`, 잠재 40×64, 길이 16 일치 — M4)으로 승격 비용이 낮고, 첫 프레임 보존·자연스러운 동역학 프라이어 기대 |
| 학습률 설계 | 베이스라인 yaml 계승 (batch 1 × accum 2, 48h 상한 참고) | 분기별 차등 LR(액션 분기 높게, LoRA 낮게), fs 조건(8fps vs 6fps, M5) 실험 포함 |
| 공통 | **촘촘한 체크포인트 저장**(사용자 규칙: 중간 끊김 대비), wall-clock 96h의 80%에서 자동 종료, 4일 예산은 "최종 1회 학습" 기준으로 역산 |  |

### 5.4 RTX 5090(32GB) 개발 가능성 — 가능

| 작업 | VRAM 소요 | 판정 |
|---|---|---|
| 1.1B 추론 (배치 1) | 12.8 GB (공식 수치) | ✅ 배치 2도 가능 |
| 11M/중형 학습 | 수 GB~10GB대 | ✅ |
| 1.1B LoRA/부분 FT | 동결분 bf16 ~2.2GB + 학습분 소량 + 활성값 | ✅ (grad checkpointing 전제) |
| 1.1B 전체 FT (AdamW) | bf16 가중치 2.2 + fp32 마스터 4.4 + 모멘트 8.8 + grad ≈ **17.6GB+활성값** | ⚠️ 한계선 — 8-bit optimizer면 ~13GB로 가능하나 권장하지 않음 |

결론: **개발은 5090에서 전부 가능**하되, 1.1B 전체 FT만은 대회 GPU(96GB) 몫으로 남긴다. 이는 분기 B의 "부분 FT+LoRA" 설계와도 일치한다.

### 5.5 Action Component(40%) 공략 — 성립하되 메커니즘 교정

**성립하는 것**:
- Action MAE는 **로컬에서 완전 계산 가능**(정답 액션을 이미 보유, CSV에 기록되는 값 자체가 점수) — 40%짜리 점수를 제출 전에 정확히 안다. 이 이점은 1차 문서 그대로 유효.
- 액션 CFG는 **이미 배선돼 있다**(C5): 학습 시 `action_dropout_prob: 0.1`로 켜고, 추론 시 `unconditional_guidance_scale`>1이면 uncond 분기에서 액션이 자동 null 처리. λ 스윕은 설정 변경 수준의 저비용 실험이다.
  - 단, 현행 uncond 분기는 **텍스트·이미지 임베딩도 함께 null 처리**하므로 순수 "액션만" guidance가 아니다. 순수 액션 CFG(다른 조건은 유지, 액션만 null)가 필요하면 uc 딕셔너리에 `act=None`만 다르게 넣는 소규모 수정으로 분리 가능.
- OSCAR식 URDF 스켈레톤 보조 조건은 "관절값→픽셀 위치" 대응을 명시적으로 주는 귀납 편향으로 여전히 유효한 **선택 실험**.

**교정하는 것**(M1 수용):
- 추출기는 프레임별 **절대 관절각 회귀기**다. "λ로 행동을 과장하면 MAE가 내려간다"는 폐기. λ는 "모델이 액션 조건을 무시하지 않게 만드는" 지점까지만 유익하고 그 이후 비단조로 가정한다.
- 따라서 40% 공략의 **본질은 추론 트릭이 아니라 학습 시 액션 조건 충실도**다: 액션 드롭아웃 학습(CFG 겸용) + 액션 분기 용량/주입 위치 실험 + (선택) 스켈레톤 조건. λ 스윕은 그 위의 마무리 손잡이로 강등.
- **wrist_roll 분포 이탈(M2) 대응도 같은 결론으로 수렴**: eval의 dim4가 train 평균에서 +1.5σ 떨어진 값에 거의 고정돼 있으므로, 평균 회귀하는 모델은 상수 손실을 먹는다. 조건을 강하게 따르는 모델만이 이 손실을 피한다. (eval 통계 기반 데이터 선별은 규칙 위반 회색지대 — 하지 않는다.)

## 7. 다음 단계 실행 순서 (바로 착수 가능 수준)

| 단계 | 내용 | 산출물 / 완료 기준 | 예상 소요 |
|---|---|---|---|
| **M0** | **로컬 모의채점 루프 + 바닥값 3종 측정** — submission_kit의 3개 채점 모델로 train 홀드아웃(예: 데이터셋당 1~2 에피소드, 200클립) 채점기 구성. 반드시 **libx264 mp4 저장→재로드 경로**로 채점(m5). 측정: ① static repeat ② 베이스라인 ckpt(제공된 `baseline_diffusion.ckpt` 그대로) ③ 정답 영상 upper bound | `score_local.py` + 바닥값 3종 수치표. **이 숫자가 백본 분기(A/B)를 결정한다** | 1일 |
| **M1** | **추론 실측** — 5090에서 11M/1.1B UNet의 스텝당 시간·배치 스케일링(1/2/4)·VRAM 측정, r 추정 → NFE 상한 확정 | (스텝, 배치, CFG) 허용 조합표 | 0.5일 |
| **M2** | **분기 결정** — M0 격차 크고 M1 통과 → 분기 B(1.1B 부분 적응). 격차 작거나 예산 불통과 → 분기 A(중형 스크래치 + 액션 특화). critic §10 재평결 조건과 동일 기준 | 결정 기록 (다음 문서) | 0.5일 |
| **M3** | **액션 CFG 파일럿** — 11M 백본에서 `action_dropout_prob: 0.1` 재학습(짧게) → λ 소표본 스윕(R6)으로 반응 곡선 확인. 순수 액션 CFG(uc 분리) 필요성 판단 | λ 반응 곡선, CFG 채택 여부 | 1~2일 (M2와 병행 가능) |
| **M4** | **본 학습** — 선택된 분기 구성으로 학습. 데이터 필터링(16f 미만 0.3% 제외, 10fps 1개 제외, 고해상 5개 리사이즈), fs 조건 A/B(분기 B만), 촘촘 체크포인트 + max_time 리밋 | v1 모델 + 모의채점 점수 | 3~4일 |
| **M5** | **제출 파이프라인** — NFE 상한 내 추론 구성 확정(스텝 수 vs CFG 트레이드오프를 모의채점으로), 216개 생성 wall-clock 실측, 조기 제출로 로컬↔리더보드 점수 정합성 검증 | 첫 제출 + 정합성 리포트 | 1일 |
| **M6** | (선택 실험) URDF 스켈레톤 보조 조건, 차원별 MAE 분석 기반 개선, few-step 증류(예산 남을 때만) | v2 모델 | 잔여 기간 |

> M0·M1이 전부의 전제다. **이 두 측정 없이는 어떤 학습도 시작하지 않는다** — 1차 문서의 실패 원인(측정 없는 서사)을 반복하지 않기 위한 규율이다.
