## 1. 왜 지금 λ=0.1 을 제출해야 하나 — 두 가설이 정반대 답을 준다

step 11,000 에서 우리가 아는 건 두 점뿐이다.

```
λ=0     0.3032489418   (정지영상과 비트 단위로 같다)
λ=0.25  0.3075219953   (+0.0043 손해)
```

두 점 사이가 어떤 모양인지 **모른다.** 가능한 모양이 둘이고, 답이 반대다:

| 가설 | 뜻 | λ=0.1 예측 | λ=0.15 예측 |
|---|---|---:|---:|
| **A. 굽은 정도가 step 15,000 과 같다** | 잔차가 조금은 도움이 된다. 작게 넣으면 이득 | **0.3000 (넘는다)** | 0.3009 (넘는다) |
| **B. 손해가 λ² 에 정비례한다** | 잔차는 언제나 손해. λ→0 에서 이득이 0 으로 죽는다 | 0.3039 (못 넘는다) | 0.3048 (못 넘는다) |

`[측정]` A 의 계산: step 15,000 의 3점(λ 0/0.25/0.5)을 2차식으로 맞추면 굽은 정도 b=0.328.
그 b 를 step 11,000 에 그대로 놓고 λ=0.25 점을 지나게 하면 위 값이 나온다.

**⇒ 로컬에서는 못 가린다. 제출해야 한다.** 이게 G6 다.

⚠ 위 두 줄은 **예측이지 근거가 아니다.** 2점에 가정 하나를 얹은 외삽이고,
009 §11 이 이 팀은 그런 외삽으로 이미 여러 번 틀렸다고 기록했다.
쓰는 곳은 딱 하나 — **"제출할 가치가 있다"** 를 보이는 것뿐이다.

## 2. 박은 판정선 셋 `[코드 gates.py]`

### G6 — λ 를 낮추면 정지영상을 넘나 (**지금 제출로 판정**)

```
제출     step 11,000 의  λ=0.1  ·  λ=0.15   (2회)
검사     두 점수 중 최저값
통과     < 0.3028489   → 정지영상을 처음 넘었다.  승자 λ 주변 ±0.05 를 한 번 더 스윕
무승부   0.3028489 ~ 0.3036489  → 정지영상과 같다. λ 축 종료
실패     > 0.3036489   → λ 로는 못 넘는다. λ 축 종료
```

밴드 ±0.0004 는 **새 숫자가 아니다.** 003 경-1 의 mp4 인코딩 흔들림을 그대로 쓴다.
S₀ 는 G3 가 실측으로 확정한 0.3032489418 이다.

**통과하면 G5 가 뒤집힌다** — 012 §5 에서 ❌ 였던 *"최고 제출이 S₀ 를 못 넘었다"* 가 해소되고,
008 §8-① 의 사망선(*8/13 까지 S₀ 를 넘어라*)도 3일 앞당겨 충족된다.

### G7 — 학습량을 늘리면 좋아지나 (**곡선 4점 이상 모이면 판정**)

```
제출     λ 하나로 고정하고  step 17,000 · 20,000 · 25,000 · 30,000
         🚨 λ 를 섞으면 두 축이 뒤엉킨다.  G6 통과 → 승자 λ / 아니면 λ=0.25 (기존 3점과 같은 축)
검사     마지막 2점이 연속으로 최저를 갱신하는가
통과     둘 다 갱신  → 학습이 아직 점수를 사고 있다. 계속
무승부   하나만 갱신 → 보류. 다음 5,000 스텝 점을 찍고 재판정
실패     둘 다 미갱신 → 최적 학습량은 지났다. 최저 체크포인트 확정하고 학습 중단
```

왜: 014 §1 이 3점을 남겼는데 단조가 아니다. **3점으로는 모양을 모른다.**

### G8 — 30,000 을 넘겨 45,000 까지 갈까 (**step 30,000 도달 시**)

```
검사     G7 곡선의 최저점이 마지막 2점 안에 있는가
통과     있다 → 45,000 연장 승인.  full_030000.pt 에서 재개 +
         --wake-step 2000 --lam-c 0.012 --micro-batch 2 --accum 8
실패     없다 → 연장하지 않는다.  남은 GPU 를 λ 미세 스윕 · 재현 검증(013 §3)에 쓴다
```

팀메이트가 *"45,000 까지 가봐야 판단이 선다"* 고 했다. 그 판단의 **근거를 G7 곡선이 준다.**
선 없이 연장하면 G5 가 금지한 "관성으로 태우기"다.
