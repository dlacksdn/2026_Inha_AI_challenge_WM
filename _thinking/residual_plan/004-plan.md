## 2. 무엇을 만드나

### 2.1 한 그림

```
   사진 1장 ─────────────────────────────────┐
                                             │
   사진 1장 ┐                                │
            ├─→ [ 신경망 ] ─→ 변화분(잔차) ─→ ⊕ ─→ 미래 16프레임
   행동 16단계 ┘                              (더한다)
```

**왜 "변화분"만 만드나**: 배경은 거의 안 변한다. 원본 사진을 그대로 흘려보내고
**바뀌는 부분만** 만들면, 신경망이 배경을 다시 그리느라 힘을 낭비하지 않는다.

**그리고 하방이 막힌다**: 마지막 층을 0으로 초기화하면 학습 0스텝에서
변화분이 문자 그대로 0 → **출력이 정확히 정지영상**이다. 실패해도 쓰레기가 안 나온다.
(제출은 mp4 를 거치므로 ±0.0004 흔들림은 있다)

**④를 왜 20×32 로 안 내리나** (003 치-3)

```
잔차의 유효 해상도별 오라클 이득 (018 §3.7⑤ 실측)
   1/2  (160×256)  −0.038
   1/4  ( 80×128)  −0.017
   1/8  ( 40×64 )  −0.004
   1/16 ( 20×32 )  −0.0004   ← 사실상 0
```

행동이 만드는 변화는 **FiLM 을 넣은 지점의 해상도에 묶인다.** 스킵이 나르는 건

그리고 메모리를 아끼려던 이유도 사라졌다 — 킷 손실이 금지돼서 **여유가 ~28 GiB** 다.

## 3. 무엇으로 학습하나

```
L = L1(픽셀)                        ← 붕괴 방지 닻. 비중은 낮게
  + λ_f · 주파수 손실                ← 흐릿해지는 것을 막는다
  + λ_a · 자체 IDM 손실              ← 행동을 맞히게 만든다
  × 모션 가중                        ← 움직이는 곳에 무게를 준다. 비용 0
```

| 항 | 무엇인가 | 주의 |
|---|---|---|
| **L1** | 정답 영상과 픽셀로 비교 | ⚠ **이것만 쓰면 안 된다.** 흐릿한 평균으로 가고, 그게 채점에서 벌받는다(018 §5.5 실측) |
| **주파수 손실** | 선명함을 지키는 항 | OpenSTL 의 `wast.py` 에 **이미 구현돼 있다** |
| **자체 IDM** | 우리가 만든 "영상 보고 행동 맞히는" 작은 신경망. 생성 영상에 통과시켜 오차를 손실로 | ⚠ **킷 구조를 보지 말고** 외부 문헌만으로 설계한다<br>⚠ **λ 를 작게(0.01~0.05).** VP2 에서 가중치 10 이 성공률을 58%→10% 로 반토막 냈다 |
| **모션 가중** | \|정답 잔차\| 를 픽셀별 가중치로 | 우리 구조에선 공짜다 |

> **순서**: 방향(행동을 맞히는 것)이 먼저다. **선명도 항은 방향이 확인된 뒤에 켠다.**
> 방향이 틀린 상태에서 선명하게 만들면 **틀린 움직임이 더 선명해질 뿐**이다(018 §9-d).
