## 무엇을 물었나

우리가 만들 결정론 회귀는 **필연적으로 흐릿한 영상**을 낸다.
여러 그럴듯한 미래의 한가운데를 찍기 때문이다. 그럼 **얼마나 흐려도 되나?**

문헌은 "DINOv2 는 흐림에 비교적 관대하다"고 말하지만, 동시에 **약한 흐림에서만**
그렇다고도 한다. 그리고 결정적으로 **우리가 서 있는 지점이 문헌의 지점과 다르다.**

```
  분류 문제의 감각:  코사인 유사도 0.85 면 "확실히 비슷하다"
                    (서로 다른 이미지 쌍이 0.3~0.5 이므로)

  우리의 작동 범위:  같은 장면 이웃 프레임끼리 0.99 근처
                    여기서 0.98 → 0.90 으로 떨어지면 거리는 0.02 → 0.10, **5배**
```

**남의 감각을 옮겨 쓰면 크게 틀린다. 그래서 직접 쟀다.**
정답 영상에 흐림을 걸어 **정답 자신과** 채점했다. 순수한 흐림의 비용이다.

## 판정 (판정선은 017 §8.4 에 측정 전 고정했다)

```
  눈금:  잔차 노선의 이득만큼 흐림 세금이 커지면 이득이 통째로 사라진다.

  세금이 눈금을 넘는 최소 σ 를 σ* 라 하면 (σ=1px +0.00973, σ=2px +0.04248 사이 선형보간)
    눈금 0.01690 (k=4 작동점)  →  σ* ≈ 1.22px
```

## ⚠ 이게 C 설계에 직접 걸린다

문헌이 "우리 규모로 충분하다"며 인용한 **128×128** 설계(Interactive World Simulator,
RSS 2026)는 **우리 채점에 너무 작다.**

```
  채점 공간 320×512 (내용은 320×427, 나머지는 검은 띠)
  128×128 모델의 유효 해상도 = 세로 128/320 ≈ 1/2.5   ← 예산 1/2 미달
```

**⇒ C 의 출력 해상도는 최소 160×256, 안전하게는 채점 해상도 그대로 320×512.**

## ⚠ 두 가지 유보

**① 이 절과 잔차 뭉갬 측정은 "독립"이 아니다.** 둘 다 같은 연산(area 축소 + bilinear 확대)을
쓰고, 그 연산이 선형이라 항등식으로 묶여 있다:

```
  addblur_k = static + coarse_k(정답 − static) = coarse_k(정답) + (I − coarse_k)(static)
              └ 잔차 뭉갬 열 ┘                    └ 이 절의 열 ┘
```

**근거는 하나이고 나머지는 그 따름정리다.**
처음에 "독립 측정 둘이 같은 답을 냈다"고 쓴 것은 거짓이라 정정했다.

**② 대리값 가정이 연산 선택에 민감하다.** `blur_residual` 을 독립 구현
(`avg_pool2d` + nearest 확대)으로 바꾸니 **최대 상대차 20.52%** 다.

```
  addblur4 의 ΔDV   원본 −0.01037   독립 구현 −0.00132   ← 이득이 거의 사라진다
  addblur2 의 ΔDV   원본 −0.03101   독립 구현 −0.03597   ← 이득이 더 커진다
```

**곡선의 방향(고해상도가 낫다)은 유지되지만 크기는 연산에 따라 크게 달라진다.**
구체적 숫자를 설계 근거로 인용할 때는 이 민감도를 반드시 붙여야 한다.

## 참고 — 잔차 표현은 공짜가 아니다

같은 1/2 해상도에서 두 방식을 나란히 놓으면 **잔차가 진다.**

| 1/2 해상도에서 | DINO | Video | TOTAL | static 대비 |
|---|---:|---:|---:|---:|
| 정답 전체를 1/2 로 | **0.03174** | 0.01305 | 0.50183 | **−0.05849** |
| static + 1/2 잔차 | 0.10271 | **0.00809** | 0.52234 | −0.03798 |

DINO 에서 3배 넘게 차이 난다. **"고르게 흐리지만 내용이 맞는 그림"** 이
**"부분적으로 선명하지만 부분적으로 낡은 그림"** 보다 낫다는 뜻이다.

**그런데 이 표로 설계를 정하면 안 된다.** 둘 다 오라클이라 **모델이 무엇을 배워야 하는지**를
전혀 반영하지 않는다.

```
  프레임 전체를 예측하는 모델 : 배경까지 **다시 그려야** 한다. 실패하면 쓰레기 영상
  잔차를 예측하는 모델        : 배경은 **그냥 흘려보낸다**. 실패하면 정확히 static
```

**잔차의 근거는 여전히 성능이 아니라 위험 구조다.**
