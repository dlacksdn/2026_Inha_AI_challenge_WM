## 2. ⚠ 012 §1 의 결론이 반증됐다 — 왜 틀렸나

012 §1 은 이렇게 썼고, 013 §1-a 가 검수로 확인해 줬다:

> *"손해가 λ² 에 거의 정확히 비례한다 … **정지영상을 이기는 λ 가 존재하지 않는다**"*

**틀렸다.** λ=0.15 가 0.0157 이긴다 — 그 문서가 "잡음 이하"라 부른 이득(0.0003)의 **50배**다.

### 어디서 틀렸나

012 는 **λ 3점(0 · 0.25 · 0.5)** 에 2차식을 맞췄다. 그 3점 사이에 **0.25 미만이 하나도 없다.**
그래서 0.15 부근에 있는 골짜기를 **볼 수가 없었다.** 2차식은 골짜기가 하나뿐이라고 가정하는데,
실측은 그 가정을 깬다 `[측정]`:

```
기울기 (Δ점수 ÷ Δλ)
  λ 0    → 0.1     −0.060
  λ 0.1  → 0.15    −0.193      ← 더 가팔라졌다
  λ 0.15 → 0.25    +0.199
```

볼록(2차)이면 기울기가 계속 커져야 한다. **−0.060 → −0.193 은 반대다.** 이 곡선은 2차가 아니다.

### 교훈 — 009 §11 을 λ 축에서 또 어겼다

```
009 §11   "몇 개 점으로 외삽하지 마라. 이 팀은 3점 외삽으로 두 번 연속 틀렸다"
012 §1    λ 3점으로 외삽했다  →  세 번째로 틀렸다
```

**같은 실수를 학습량 축에서 다시 하지 않으려고 G7 을 4점 이상으로 등록해 뒀다**(015 §2).
그 등록이 지금 값을 한다.

⚠ 이번 골짜기도 **4점짜리다.** 최소점이 정확히 어디인지 아직 모른다. 외삽하지 않고 **잰다**(§4).
