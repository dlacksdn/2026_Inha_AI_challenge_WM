## 0. 한 줄

> **하루 10회는 개인당이 아니라 팀당이었다.** 오늘 제출이 이미 끝났다.
> G7(학습량 곡선)·G8(연장)은 **판정할 데이터를 오늘 안에 못 받는다.** 무효 처리한다.

---

## 1. 013 §5-3 이 답을 얻었다 `[문서 — 사용자가 주최/팀에서 확인]`

013 §5 는 확인 못 한 것 6개를 남겼는데 그 3번이 이것이었다:

> *"제출 10회가 팀 단위인지 계정 단위인지 — 문서에 없다"*

**팀 단위다.** 이 한 줄이 오늘의 모든 계획을 바꾼다.

```
오늘 branch C 가 쓴 것   7회  (λ=0 · 0.5 · 0.25@15k · 0.25@7k · 0.25@11k · 0.1@11k · 0.15@11k)
팀 전체 소진             10회 → 오늘 남은 것 0회
앞으로의 배분            branch C 하루 3회 (사용자 결정)
```

⚠ **이건 예산이 아니라 공유 자원이다.** 우리가 쓰면 팀메이트가 못 쓴다.
오늘 우리가 7회를 쓴 것이 팀메이트의 실험을 막았을 수 있다. **조율은 사용자만 할 수 있다.**

---

## 2. G7·G8 을 무효 처리한다 (통과도 실패도 아니다)

015 에 등록할 때 **개인 10회**를 전제로 짰다. 그 전제가 사실이 아니었다.

| 게이트 | 원래 계획 | 지금 |
|---|---|---|
| **G7** | 오늘 3회로 λ=0.15 곡선 4점 → 판정 | ❌ 오늘 제출 0회. **판정 불가** |
| **G8** | 30,000 도달(22:50) 시 G7 곡선으로 판정 | ❌ G7 이 없으므로 **판정 불가** |

**중요 — G7 은 이제 다시 살려도 값이 없다** `[추측이 아니라 산술]`:

```
G7 이 답하는 질문   "학습을 계속할까"
그 질문이 사는 기간  GPU 를 쓸 수 있는 동안 = 내일 14:00 까지
그런데 판정에 필요한 3회는 내일치다 → 답이 나올 때쯤 학습은 이미 끝나 있다
```

**⇒ 내일 14:00 이후 이 노선의 문제는 "얼마나 학습할까"가 아니라
"이미 있는 체크포인트 중 어느 것을 어떤 λ 로 낼까"다.** 학습 정책이 아니라 **탐색 문제**로 바뀐다.

## 3. 그래도 45,000 연장은 그대로 간다 — G8 을 어긴 것이 아니다

G8 의 fail 조항은 *"연장하지 않는다. GPU 예산을 관성으로 태우지 않는다"* 였다.
그 조항이 성립하려면 **아낀 GPU 를 쓸 다른 데가 있어야 한다.** 지금은 없다:

```
GPU 는 내일 14:00 에 다음 사용자에게 넘어간다.  아껴도 이월되지 않는다
G8 fail 이 지정한 대체 용처 둘:
  · λ 미세 스윕      → GPU 100초면 끝난다. 15시간이 필요 없다
  · 재현 리허설      → 팀메이트 자산이 없어 못 한다 (013 §3-② 미실행)
⇒ 연장을 안 하면 GPU 15시간이 그냥 논다. 논다고 아무도 이득을 안 본다
```

**⇒ G8 은 "실패"가 아니라 "무효(moot)"다.** 통과했다고 쓰지 않는다.
연장의 근거는 게이트가 아니라 **"쓰지 않으면 사라지는 자원이고 위험이 0"** 이다.

```
위험 0 인 이유   새 폴더(train_*_long45)에 쌓는다. 기존 체크포인트를 안 건드린다
얻는 것         35,000 · 40,000 · 45,000 세 개의 선택지.  탐색 문제에서 후보는 많을수록 좋다
```

**⚠ 대안 하나를 기록해 둔다** — 같은 학습을 15,000 더 태우는 대신 **미구현 선명도(주파수) 항**
(014 §5-5)을 켠 새 팔을 돌릴 수 있었다. 채택하지 않은 이유: ① 코드가 없다 ② 004 §3 이
*"방향이 틀린 채 선명하게 하면 더 나쁘다"* 고 경고했고 아무도 안 재봤다 ③ 하루 3회로는
새 팔을 평가할 예산이 안 나온다. **버린 것이 아니라 미룬 것이다.**

## 4. 하루 3회 — 무엇부터 재나

내일부터 8/20 까지 10일 × 3회 = **약 30회**. 지금 준비된 후보가 그보다 많다.

### 우리가 실제로 아는 것 (전부 step 11,000)

| λ | 리더보드 | S₀ 대비 |
|---:|---:|---:|
| 0 | 0.3032489 | 0 |
| 0.1 | 0.2972014 | −0.0060 |
| **0.15** | **0.2875745** | **−0.0157** ← 최고 |
| 0.25 | 0.3075220 | +0.0043 |

**다른 체크포인트에서는 λ=0.15 를 한 번도 안 재봤다.** 이게 제일 큰 공백이다.

### 두 축의 성격이 다르다

```
λ 축      골짜기가 확인됐고 바닥을 아직 못 찾았다.  비교적 확실한 이득
step 축   λ=0.25 에서는 11,000 이 최고였다.  λ=0.15 에서도 그런지 모른다.  도박
```

⚠ **여기서 제안을 멈춘다.** 배분은 팀 공유 자원이고, 팀메이트 노선과의 조율은
사용자만 할 수 있다. 우리 몫 3회가 확정되면 그때 판정선을 먼저 박고 고른다.
