## 0. 30초 요약 — 판단이 바뀌는 것만

```
① ⭐ 우리 DINO 는 "PSNR형"이 아니라 "LPIPS형"이다.  판단이 뒤집힌다.
   근거는 우리 자신의 측정 — 픽셀 평균이 픽셀 L1 을 −10.4% 개선했는데 채점 DV 는 +20% 악화됐다.
   PSNR형이면 흐릴수록 좋아졌어야 한다.  ⇒ 선명하게 만드는 항이 점수를 올린다.
   ⚠ 단 **방향이 맞을 때만.**  방향이 섞이면 선명도는 틀린 움직임을 더 선명하게 그린다.
   ⇒ 순서가 정해진다: **방향 먼저, 선명도는 그 다음.**

② ⭐ R3D(30%)는 "시간 지표"가 아니라 "프레임 선명도 지표"다.
   시간 모델링이 아예 없는 2D 모델과 R3D-18 의 Kinetics 정확도 차이가 2.4%p 뿐이다.
   그리고 112×112 로 줄이는 것이 우리 흐림을 거의 다 삼킨다.
   ⇒ **시간축에 연산을 더 쓰는 근거를 Video 30% 에서 찾지 마라.** Action 40% 에서 찾아라.

③ ⭐ 우리가 하려는 것(생성 영상 → IDM → 행동 MAE 를 미분가능 보조손실로)은 **문헌에 전례가 없다.**
   비슷한 배치를 한 논문 둘(RLIR·EVA)은 전부 미분 불가능한 RL 보상이었다.
   그리고 EVA 가 보고한 퇴화 모드 중 하나가 정확히 **"static behaviors"(정지)** 다.
   ⇒ 우리 리더보드 함정(정지영상 0.30325)과 **같은 축**이다.  감시 장치가 필수다.

④ ⭐ 대리(proxy) 손실은 "그럴듯해 보이는 것"이 아니라 **"진짜 점수와의 순위상관"**으로 고른다.
   가장 자연스러워 보이던 대리가 상관 −0.21, 살짝 바꾼 변형이 0.91 인 실측이 있다.
   ⇒ 대리를 고르기 전에 **우리 데이터에서 상관을 먼저 재라.**

⑤ **무작위로 초기화한(학습 전혀 안 한) 네트워크의 특징도 지각 손실로 작동한다.**
   사전학습 가중치와 차이가 0.02~0.06%p 뿐이라는 측정이 있다.
   ⇒ **라이선스·규정 위험이 0 인 대리 후보가 실재한다.**
```

## 1. [최우선] 방향을 어떻게 맞히나

배경 — 018 §9-d 가 오라클로 만든 격자:

```
  A-1 방향이 섞임                    A-2 방향은 맞고 세기만 약함
    해상도를 올릴수록 나빠진다           세기 25% 만 맞혀도 이긴다
    (α=0.5 : +0.030 손해)              (α=0.25 : −0.010 이득)
```

### 1.1 행동 주입 형태 — 논쟁은 끝났다

**Nano World Models** ([2605.23993](https://arxiv.org/abs/2605.23993)) Table 3 — *RT-1 로봇 데이터, 백본 고정, 지표 PSNR*

| 주입 방식 | PSNR |
|---|---:|
| FiLM / AdaLN / AdaLN-fuse / 단순덧셈 | 23.20 / 23.19 / 23.10 / **23.07** |
| **Cross-attention** | **20.82** |

[측정] **cross-attention 만 −2.38dB 로 혼자 떨어진다. 나머지 넷의 폭은 0.13dB — 동률이다.**
⚠ 지표가 PSNR 이다. 우리 채점(특징거리 60% + 행동 MAE 40%)과 다르다.

**⚠ 금지 문구를 정밀화한다.** **CAPE** ([2606.07304](https://arxiv.org/abs/2606.07304))는
**행동을 query 로, 시각 토큰을 key/value 로** 쓰는 cross-attn 으로 성공했다.
Nano WM 에서 진 것은 그 반대(행동이 key/value)다.
⇒ 금지는 **"행동을 key/value 로 넣는 cross-attn"** 에만.

### 1.2 ⭐ 자체 학습 IDM 헤드 — 새 1순위, 그런데 **전례가 없다**

킷의 action extractor 를 못 쓰므로, **우리가 train 데이터로 직접 학습한 역동역학 헤드**
(생성 16프레임 → IDM → 행동 역추정 → 준 행동과 MAE)가 Action 40% 를 겨냥하는 유일한 경로다.

**먼저 좋은 소식** — **RLIR** ([2509.23958](https://arxiv.org/abs/2509.23958)) Table 2
*Minecraft world model 700M. 생성 영상을 동결 IDM 에 통과시켜 보상으로*

| 보상 | 행동추종 F1 ↑ | FVD ↓ | PSNR ↑ |
|---|---:|---:|---:|
| 베이스라인 | 0.70 | 231 | 15.32 |
| **픽셀(L1+LPIPS)** | **0.71** | 228 | 15.47 |
| **IDM 보상** | **0.81** | 207 | 15.78 |

[측정] **픽셀 보상은 행동추종을 거의 못 올렸고(0.70→0.71) IDM 보상은 크게 올렸다(→0.81).**
우리 실측(픽셀 개선 = 채점 악화)과 같은 방향의 독립 증거다.
⚠ 이산 행동 F1 이지 연속 관절 MAE 가 아니다. IDM 이 외부 데이터 2,000시간으로 학습됐다(우리는 금지).

**⚠ 그런데 나쁜 소식이 더 크다.**

> **[찾지 못함] 생성된 최종 픽셀에 IDM 을 통과시키고 그 오차를 잔차 헤드까지 역전파한 논문이 없다.**
> 실제로 그 배치를 한 RLIR·EVA 는 **전부 GRPO 보상(미분 불가)** 이었고,
> Vidar 는 추론 시 디코더였다. **우리가 하려는 것은 문헌에 전례가 확인되지 않은 형태다.**

### 1.3 IDM 의 함정 넷 — 전부 정량 근거가 있다

**① ⭐ 동결해도 해킹당하고, 퇴화 모드에 "정지"가 있다**

**EVA** ([2603.17808](https://arxiv.org/abs/2603.17808)) Appendix C 원문:

> "increases in the IDM-based reward generally correlate with improved kinematic plausibility.
> However, this correlation may break down with prolonged optimization, where we occasionally
> observe degenerate high-reward behaviors" — 퇴화 유형에 **"static behaviors"** 포함.

[주장] 빈도·정도의 수치는 없다. 처방은 **"검증 rollout 품질 기준의 체크포인트 선택 + 조기 종료"**.

> **⇒ 우리 리더보드 함정과 정확히 같은 축이다.** 정지영상이 0.30325 로 이미 강하다.
> IDM 손실이 "안 움직이면 행동도 0 이니 안전하다" 쪽으로 모델을 끌 수 있다.

**② IDM 은 생성 영상에서 처참하게 과적합한다 — 마스크가 답이다**

**Vidar MIDM** ([2507.12898](https://arxiv.org/abs/2507.12898)) Table 3

| IDM | 학습 정확도 | **테스트 정확도** | 테스트 l1 오차 ↓ |
|---|---:|---:|---:|
| 평범한 ResNet | 99.9% | **24.3%** | 0.0430 |
| **+ 공간 마스크 + L1 희소 정규화** | 99.9% | **49.0%** | **0.0308** |

[측정] 마스크가 테스트 정확도를 **두 배**로 올렸다. 손실식: `L = l(â−a) + λ‖m‖₁`,
`m = U(x)`(U-Net 마스크), `â = R(round(m)⊙x)`. 즉 **로봇팔 영역만 보게 강제**한다.
⚠ 이건 IDM 구조 비교이지 보조손실 on/off 가 아니다. 92M 파라미터.

**③ 함께 학습하면 붕괴한다 — 그런데 완전 동결도 정체시킨다**

**CoLA-World** ([2510.26433](https://arxiv.org/abs/2510.26433))

[측정] IDM 을 world model 과 곧바로 공동학습하면 붕괴한다
("the utilization rate of the VQ codebook drops to zero after an initial brief increase").
처방은 **warm-up**: world model 을 동결한 채 IDM 만 먼저 학습 → 그 다음 공동학습.
반대로 **IDM 을 끝까지 완전 동결하면 world model 성능이 정체**된다고도 보고한다.
⚠ 비지도 VQ 잠재행동 설정이다. 우리는 준 행동(6D 실수)으로 지도학습하므로 **이 특정 붕괴는 안 올 수 있다.**

**④ 동결 크리틱으로 완전 역전파하면 빨리 무너진다**

**AlignProp** ([2310.03739](https://arxiv.org/abs/2310.03739)) 4.2절:
[측정] 완전 BPTT 는 **2에포크 만에 모드 붕괴** — "irrespective of the input conditioning prompt,
the model consistently generated the same image". 완화책은 **무작위 절단 역전파**(K~Uniform(0,50)).

### 1.4 모션 가중 손실 — 우리 잔차 구조에 공짜로 붙는다

**MotiF** ([2412.16153](https://arxiv.org/abs/2412.16153)) — ⭐ **16프레임 320×512. 우리와 규격이 같다**

[측정] 광류 세기로 픽셀별 손실 가중치를 준다. `σ(x)=1/(1+e^{100(0.05−x)})` 로 [0,1] 정규화, λ=1.0.
Table 2 어블레이션(왼쪽이 MotiF, 오른쪽이 베이스라인):

| 변형 | TI2V Score | Object Motion | Overall Quality |
|---|---|---|---|
| **MotiF 손실 뺌** | 63.1 / 36.9 | 32.9 / 16.4 | 18.2 / 20.8 |
| **역가중(정지 영역 강조)** | 61.9 / 38.1 | 34.9 / 15.4 | **14.3** / 17.8 |

[측정] **역가중이 더 나쁘다.** 움직이는 곳에 무게를 주는 방향이 맞다.
같은 방향: **FlowWAM** — 이 항을 빼면 성공률 89.8% → 83.9%.

> **⇒ 우리에게는 공짜다.** 잔차 자체가 `x_t − x_0` 이므로 **|정답 잔차| 를 그대로 가중치로 쓴다.**
> 추가 연산 ≈ 0. RAFT 도 필요 없다.
> ⚠ 두 논문 모두 지표가 **"움직임의 양"이지 "정확도"가 아니다.** 방향이 틀린 채 커지면 우리는 더 나빠진다.

### 1.5 흐름은 **보조 감독**으로만 — 출력 타깃으로 바꾸지 마라

[측정] **AVDC** ([2310.08576](https://arxiv.org/abs/2310.08576)): 확산모델이 흐름을 **직접 생성**하면
Meta-World 성공률 **43.1% → 13.7%**. 흐름장은 물체 하나만 움직이면 희소해진다 — **우리 로봇 팔이 그 경우다.**
[측정] **FOFPred** ([2601.10781](https://arxiv.org/abs/2601.10781)) Table 3: 흐름을 조건으로 넣으면
개선이 모션 축에 몰린다 — **Motion Fidelity +11.4%(상대) vs PSNR +3.5%(상대).**

### ⇒ 우리 설계에 주는 것

1. **주입 형태는 확정. 더 시간 쓰지 마라.** per-frame FiLM 또는 AdaLN. 금지는 "행동이 key/value 인 cross-attn".
2. **1순위 = 자체 IDM 헤드 보조손실.** 단 **전례가 없으므로 안전장치를 함께 넣는다.**
   - **IDM 은 진짜 영상으로 먼저 학습하고 동결**한 뒤 보조손실로 켠다(warm-up 순서).
   - **λ 는 작게.** 문헌 실측 안전 구간 0.01~0.05. 채점 가중치 0.4 를 그대로 옮기지 마라.
   - **L1(L2 아님).**
   - **IDM 에 공간 마스크 + L1 희소 정규화**를 넣어라. 없으면 테스트 정확도가 반토막 난다.
   - **정지 감시 필수**: 잔차 norm 과 예측 행동의 크기를 매 스텝 로깅. 둘 다 죽으면 즉시 중단.
3. **2순위 = 모션 가중 손실.** |정답 잔차| 를 가중치로. 비용 0. 역가중은 하지 마라.
4. **하지 마라**: 흐름을 출력 타깃으로 / 흐름 stage-1 모델 따로 / IDM 을 처음부터 공동학습.

## 2. [최우선] R3D-18 은 무엇에 반응하나

### 2.1 코드로 확인한 채점기 배선 3종

`open/submission_kit/feature_csv_utils.py`, `action_extractor.py` 를 직접 읽었다.

| | DINO (30%) | R3D (30%) | **Action (40%)** |
|---|---|---|---|
| 모델 | DINOv2 ViT-S, **CLS 384차원** | torchvision `r3d_18`(Kinetics-400), **512차원** | Conv3d + **양방향 GRU**, 4.59M |
| 입력 | 518×518, 위아래 37.5% 검은 패딩 | **112×112 로 찌그러뜨림**(세로 2.86배·가로 4.57배) | **320×512 그대로** |
| 시간축 | 안 본다(프레임별) | 16프레임 한 클립 | 16프레임 전부 |
| 프레임 서브샘플 | ✅ 가능 | ❌ | ❌ |

**Action extractor 구조가 킷에 소스로 공개돼 있다** (checkpoint 만이 아니다):
`Conv3d(3,7,7) s(1,2,2)` → Residual3DBlock 8개(채널 32→32→64→128→128, 공간 16배 축소,
**시간축 축소 없음**) → 공간평균 → 양방향 GRU(256) → MLP → 6차원. **학습 손실은 MSE, 채점은 MAE.**
⇒ 이 구조를 참고해 우리 IDM 을 만들 수 있는지가 **주최 질의 ③**이다.

### 2.2 ⭐ R3D 는 시간보다 프레임 외형에 반응한다 — 증거 넷

**① 프레임 품질을 고정하고 시간만 어긋내면 FVD 는 조금만 움직인다**

**On the Content Bias in FVD** ([2404.12391](https://arxiv.org/abs/2404.12391), CVPR 2024) Table 1
*I3D 특징. **FVD 는 수천 개 집합의 분포 거리**이고 우리는 영상 1쌍의 코사인 거리다*

| 데이터셋 | FID (공간→시공간) | **FVD (공간→시공간)** |
|---|---|---|
| UCF-101 | 133.15 → 133.69 (+0.4%) | 1460.18 → 1705.27 (**+16.8%**) |
| Sky Time-lapse | 79.11 → 79.35 (+0.3%) | 211.08 → 286.39 (**+35.7%**) |
| FaceForensics | 80.42 → 79.57 (−1.1%) | 354.49 → 367.35 (**+3.6%**) |

### 2.4 흐림 — 112×112 축소가 우리 예산을 삼킨다

**산수가 핵심이다.** 320×512 → 112×112 는 세로 2.857배·가로 4.571배 축소.

```
  원본 σ = 1.9px  →  R3D 입력에서 세로 0.67px, 가로 0.42px  (부분픽셀 흐림)
```

우리 실측(018 §4.2, n=96 — *정답을 흐리게 해서 정답 자신과 채점*):

| 변형 | Video 성분 | **Score 기여**(×0.3) |
|---|---:|---:|
| σ=1px | 0.01319 | 0.0040 |
| σ=2px | 0.04958 | 0.0149 |
| **σ=4px** | 0.18517 | **0.0556** ← 절벽 |
| 해상도 1/2 | 0.01305 | 0.0039 |

문헌의 유일한 경고 — **Kinetics400-P** ([2207.01398](https://arxiv.org/abs/2207.01398), CVPR 2023):
[측정] R3D 의 흐림 강건성 γr=**.70**(원래 정확도의 30% 손실), Transformer 계열은 .79~.82.
**그러나 시간 손상에는 γa=.98 / γr=.97 로 사실상 무반응이다.**

### ⇒ 우리 설계에 주는 것

1. **흐림 예산의 병목은 Video 가 아니라 DINO 다.** σ=1px 에서 Video 의 Score 기여는 0.0040 뿐.
   **선명도 예산은 DINO 쪽에 몰아라.**
2. **σ=4px 는 절벽.** 결정론 회귀는 뒤 프레임일수록 흐려진다. **프레임별 유효 σ 를 학습 중 감시**하고
   마지막 프레임이 3px 를 넘지 않게 하라.
3. **⭐ 시간축 연산 증설의 근거를 Video 30% 에서 찾지 마라.** 1/8(389ms) → 1/4(6,238ms) 의
   16배 투자는 Video 기준으로 근거가 없다. **근거를 "Action MAE 가 줄어든다"로 바꿔 잡아라.**
4. **Video 는 "지키는 항목"이다.** 정지영상의 Video 성분이 0.09110 이므로
   **여기서 벌 수 있는 최대 이득은 0.3 × 0.0911 = 0.0273 뿐**이다.
   목표 격차(0.30325→0.25 = 0.053)의 절반. **승부는 Action 40% 와 DINO 30% 에서 난다.**
5. **완전 정지만은 피해라.** 잔차 norm 로깅.
6. **[추측] 이방성 여지**: 가로가 세로보다 1.6배 더 축소되므로 R3D 는 가로 고주파를 거의 못 본다.
   **문헌이 아니라 리사이즈 산술에서 나온 추론이다.** 30분 실험으로 먼저 확인하라(§6-D).

## 3. 흐릿함을 줄이는 법

### 3.1 ⭐ 판단이 뒤집힌다 — 우리 DINO 는 LPIPS형이다

```
  픽셀 평균내기(= 흐리게 하기) 결과 (018 §5.5, 우리 실측, n=96)
     픽셀 L1   12.343 → 11.054   −10.4% 개선
     채점 DV    0.0943 → 0.1132  +20% 악화

  DINO 가 "PSNR형"(흐림에 관대)이었다면 → 흐릴수록 좋아졌어야 한다.  정반대였다.
  ⇒ 우리 DINO 는 흐림을 픽셀 지표보다 더 심하게 벌한다 = LPIPS형이다.
```

문헌이 지지한다.

**DreamSim** ([2306.09344](https://arxiv.org/abs/2306.09344)) Table 5 — *NIGHTS 사람 2AFC 일치율*

| 지표 | 일치율 |
|---|---:|
| PSNR / SSIM | 57.1% / 57.3% |
| LPIPS | 70.7% |
| **DINO ViT-B/16 CLS 코사인** | **90.1%** |

[측정] **우리 DINO 성분은 픽셀 지표 계열이 아니라 지각 지표 계열이다.**
⚠ DreamSim 자체는 DINO+CLIP+OpenCLIP **앙상블+LoRA** 다. 우리와 같은 것은 위 `DINO CLS 90.1%` 행 하나다.

**PredBench** ([2407.08418](https://arxiv.org/abs/2407.08418), ECCV 2024) — *CityScapes 128×128*

| 모델 | PSNR ↑ | **LPIPS ↓** |
|---|---:|---:|
| SimVPv1 (결정론) | **27.91** | 0.1240 |
| MCVD (확산) | 19.05 | **0.0822** |

[측정] **PSNR 은 8.86dB 차이로 결정론이 이기는데 LPIPS 는 33.7% 차이로 확산이 이긴다.**
특징공간 full-reference 거리는 **선명함에 상을 준다.**

### 3.2 ⭐ 그러나 순서가 있다 — 방향이 먼저다

```
  선명하게 만드는 것 = 해상도를 올리는 것과 같은 성질의 투자다.

  A-1 (방향 섞임)  → 선명하게 만들면 **틀린 움직임이 더 선명해진다.**  손해
  A-2 (방향 맞음)  → 선명하게 만들면 **맞는 움직임이 더 정확해진다.**  이득
```

> **⇒ §3.1 의 결론은 A-2 에 떨어졌을 때만 참이다.**
> **주파수 손실은 2순위. 방향을 확인한 다음에 넣어라**(§6-A).

### 3.3 무엇을 쓰나 — GAN 이 아니라 주파수 손실

**Focal Frequency Loss** ([2012.12821](https://arxiv.org/abs/2012.12821), ICCV 2021)
*CelebA 64×64. **결정론 오토인코더/VAE** — 우리와 같은 "조건부 평균 흐림" 병리*

| 모델 | PSNR ↑ | LPIPS ↓ |
|---|---:|---:|
| VAE | 19.961 | 0.217 |
| **VAE + FFL** | **22.954** (+2.99dB) | **0.143** (−34.1%) |

[측정] **픽셀 지표와 지각 지표가 동시에 좋아진 유일한 사례다.**
[측정] **위상·진폭 어느 쪽도 빼면 안 된다** (제거 시 LPIPS 0.199 → 0.407 / 0.539 로 붕괴).

**Fourier Space Losses** ([2106.00783](https://arxiv.org/abs/2106.00783), ICCV 2021):
[측정] GAN 없이 **LPIPS −30.0% 를 PSNR −1.03dB 에** 샀다(DIV2K 4× SR).

**넣지 말 것 — GAN 항.** 문헌의 GAN 이득은 전부 우리에게 안 오는 프로토콜이다:
SAVP 는 **best-of-100**, Mathieu 는 1~2프레임 예측, ESRGAN 계열은 무참조 지표.

### ⇒ 우리 설계에 주는 것

1. **"우리 DINO 는 흐려도 된다"는 읽기는 틀렸다.** 데인 것은 "지각항이 나쁘다"가 아니라 **"평균내기가 나쁘다"**였다.
2. **순서: 방향 먼저, 선명도 그 다음.** 어기면 A-1 격자를 재현한다.
3. **선명도 항 1순위는 Focal Frequency Loss.** 잔차 헤드 출력에 프레임별 `rfft2` → 정답과의
   진폭·위상 차이에 focal 가중. 320×512×16 에서 비용은 무시할 수준. **위상·진폭 둘 다 넣어라.**
4. **GAN 은 넣지 마라.** 없던 디테일 생성 → Action 40% 를 흔든다.

### 4.1 대리는 "그럴듯함"이 아니라 **"순위상관"**으로 고른다

> - **CMMD** ([2401.09603](https://arxiv.org/abs/2401.09603)): 같은 왜곡 이미지에서 FID 21.40→18.02(**좋아짐**), CMMD 0.721→1.190(**나빠짐**)

⇒ **§6-I 를 반드시 먼저 재라.** 문헌 상관을 믿고 대리를 고르면 안 된다.

### 4.2 ⭐ 무작위 초기화 특징 — 규정 위험 0 인 후보

**Generic Perceptual Loss** ([2103.10571](https://arxiv.org/abs/2103.10571), CVPR 2021) Table 1
*Cityscapes 의미분할. 픽셀 손실만 = 69.60 mIoU*

| 백본 | 무작위 초기화 | 사전학습 |
|---|---:|---:|
| GoogleNet | 68.91 | 68.90 |
| ResNet18 | 70.16 | 70.14 |
| VGG16 | 70.68 | 70.71 |
| **VGG19** | **71.25** | 71.19 |

[측정] **무작위와 사전학습의 차이가 0.02~0.06%p 뿐이다. 반면 구조를 바꾸면 2.35%p 차이가 난다.**
저자 결론: **"what matters is the network structure instead of the trained weights."**
⚠ GoogleNet(68.91)은 픽셀 손실만(69.60)보다 **나쁘다** — 구조를 잘못 고르면 손해다.

**같은 방향 하나 더** ([2509.20878](https://arxiv.org/abs/2509.20878)) — *DIV2K 4× SR*
[측정] **적대항 없는 설정**(= 우리 조건): 무작위 VGG-16-R 57.99 vs 사전학습 VGG-16 59.37 — 거의 같다.
**적대항이 있으면 역전**한다(55.71 vs 61.80).

**⚠ 그러나 지표로는 쓰지 마라** — LPIPS 원논문 ([1801.03924](https://arxiv.org/abs/1801.03924)) Table 5:
[측정] 무작위 가우시안 네트워크의 사람 2AFC 일치율 **64.3%** — L2(63.2%)보다 겨우 1.1%p 높고
학습된 LPIPS(69.8%)보다 5.5%p 낮다. **손실로는 되지만 지표로는 L2 수준이다.**

**참고 — 다른 자기지도 특징도 상당히 전이된다.** REPA ([2410.06940](https://arxiv.org/abs/2410.06940)) Table 2
*SiT-L/2, ImageNet 256×256, 400K. 정렬 대상 인코더만 교체*

|---|---:|

| CLIP-L | 11.0 |
| **DINOv2-B** | **9.7** |

[측정] **DINOv2 가 아닌 인코더로도 18.8 → 11~12.5 의 큰 이득**이 난다. 단 DINOv2 가 최고다.

### 4.3 대리를 세게 밀면 **손실에 안 들어간 축이 무너진다**

**⭐ VP2** ([2304.13723](https://arxiv.org/abs/2304.13723)) Table 1 — *로봇 조작 영상 예측. 우리와 가장 가까운 세팅*

| 모델·과제 | 손실 | FVD ↓ | **제어 성공률** |
|---|---|---:|---:|
| FitVid · robosuite | MSE | 30.7 | 65% |
| FitVid · robosuite | +LPIPS(가중 1) | 18.0 | 67% |
| FitVid · robosuite | **+LPIPS(가중 10)** | 24.3 | **35%** |
| SVG′ · robosuite | MSE | 51.7 | 80% |
| SVG′ · robosuite | **+LPIPS(가중 10)** | 45.1 | **37%** |
| **SVG′ · RoboDesk** | MSE | 22.5 | 58% |
| **SVG′ · RoboDesk** | **+LPIPS(가중 1)** | **4.9** (4.6배 개선) | **10%** |

[측정] **마지막 행이 결정적이다. FVD 를 4.6배 개선하면서 제어 성공률이 58% → 10% 로 붕괴했다.**
우리 Score 구조(특징 60% + 행동 40%)와 **정확히 같은 위험**이다.

**같은 현상 셋 더**

- **VIGOR** ([2603.16271](https://arxiv.org/abs/2603.16271)) Table 2: 지도 미세조정이 PSNR 22.45→23.52,
  LPIPS 0.2243→0.1842 로 개선하면서 **Dynamic Degree 27.34 → 15.62 (−43%)** 붕괴.
- **VBench++** ([2411.13503](https://arxiv.org/abs/2411.13503)) 저자 인정:
  **"generating relatively static scenes can 'cheat' to get high temporal consistency scores."**
  ⇒ **우리 정지영상 0.30325 함정의 문헌적 확인이다.**
- **Text-to-Image Reward Hacking** ([2601.03468](https://arxiv.org/abs/2601.03468)) Table 2:
  흔히 쓰는 보상들이 "아티팩트가 있나"를 맞히는 정확도가 **0.39~0.68** — 동전던지기 수준으로 눈이 멀어 있다.

**얼마나 자주 일어나나** — Goodhart's Law in RL ([2310.09144](https://arxiv.org/abs/2310.09144)):
[측정] 30,400개 실험 중 **19.3%** 에서 진짜 목표가 실제로 떨어졌다. **5번 중 1번꼴.**
문제는 **어느 경우인지 사전에 모른다는 것**이다.

**앙상블이 완화한다 — 단 집계 방식이 중요하다**

- **E-LPIPS** ([1906.03973](https://arxiv.org/abs/1906.03973)): 무작위 변환 앙상블로 만들면
  착취 거리가 **16.2배 → 3.0배**, 헤시안 조건수가 **약 4,400배** 좋아진다. 사람 일치도는 거의 그대로.
- **Reward Model Ensembles** ([2310.02743](https://arxiv.org/abs/2310.02743)):
  [측정] **평균 집계는 라벨 잡음이 있으면 여전히 과최적화한다.**
  **최악값(WCO)** 또는 **불확실성 페널티(UWO)** 로 집계해야 과최적화가 사라진다.
- **Helping or Herding?** ([2312.09244](https://arxiv.org/abs/2312.09244)):
  [측정] 앙상블은 완화하지만 **없애지는 못한다.** 구성원이 같은 오류 패턴을 공유하면 같이 속는다.

### 4.4 정답을 모를 때 언제 멈추나

**⭐ ES-WMV** ([2112.06074](https://arxiv.org/abs/2112.06074)) — **정답 없이 조기 종료하는 실제 작동 절차**

```
  VAR(t) = (1/W)·Σ_w ‖ x^(t+w) − (1/W)Σ_i x^(t+i) ‖²_F        기본 W=100, 인내값 P=1000
  = "최근 W 스텝 동안 출력이 얼마나 흔들리나". 이 분산이 최소가 되는 지점에서 멈춘다.
```

[측정] 오라클 최고점과의 PSNR 갭: 실사 잡음제거(1,024장) **평균 0.92dB**,
fastMRI 8배 언더샘플링(30케이스) **평균 0.23dB**.

**Ladder** ([1502.04585](https://arxiv.org/abs/1502.04585)) — **제출 제한 하 리더보드 과적합**
[측정] "**유의미하게 좋아졌을 때만 갱신**"하는 규칙을 쓰면 오차가 제출 횟수 k 의 √k 가 아니라
**log^{1/3}** 로만 자란다. ⚠ 주최자 측 알고리즘이고 0/1 분류 손실이다. 참가자 측 제출 전략 논문은 못 찾았다.

**Beyond FVD** ([2410.05203](https://arxiv.org/abs/2410.05203)):
[측정] 체크포인트 선택 지표는 **상관과 표본 효율 둘 다**로 골라야 한다.
FVD 는 미세조정 스텝과의 순위상관이 −0.6 에 그쳤고, 5% 오차 수렴에 4,350~4,700 표본이 필요했다.

### 4.5 손실 균형 — 알고리즘을 쓰지 마라

[측정] **Do Current MTO Methods Even Help?** ([2209.11379](https://arxiv.org/abs/2209.11379), NeurIPS 2022):
CelebA 평균 오류 **단순 가중합 9.23 < PCGrad 9.35 < MGDA 9.53**.
그리고 **"학습률 하나를 성기게 튜닝할 때의 성능 변동이 랜덤 시드 대비 6~7배"** — 알고리즘 선택보다 학습률이 중요하다.
[측정] **In Defense of Unitary Scalarization** ([2201.04122](https://arxiv.org/abs/2201.04122)):
**PCGrad 는 CelebA 에서 약 35배 느리다.** RL MT50 은 15시간 → 1주일 이상. **4일 예산에서 즉시 탈락.**
[측정] **GradNorm** ([1711.02257](https://arxiv.org/abs/1711.02257)): 한 번 돌려 얻은 시간평균 가중치가
격자탐색 최적과 일치. 오버헤드 약 5%. ⇒ **알고리즘이 아니라 1회 측정 도구로 쓴다.**
[측정] **gradient 코사인이 음수면 실제로 해롭다** ([1812.02224](https://arxiv.org/abs/1812.02224)):
RotatedMNIST 45°에서 단일태스크 2.15% → 그냥 더하기 2.36% → `max(0,cos)` 게이팅 2.10%.

[주장] ⚠ **"픽셀 먼저, 태스크 나중" 커리큘럼은 수치 근거가 없다.**
ESRGAN 원문에 사전학습 유무 비교표가 **존재하지 않고**, VQGAN warm-up 도 "최소 1 epoch" 경험칙뿐이다(원문 확인).

### ⇒ 우리 설계에 주는 것

1. **⭐ 대리를 고르기 전에 상관을 재라**(§6-I). 문헌에 답이 없고, 반대 사례가 3건 있다.
2. **손실 조합은 이렇게 시작한다** (전부 킷과 무관):
   ```
   L = L_pixel(L1, 낮은 비중)                    ← 붕괴 방지 닻
     + λ_f · L_freq(Focal Frequency)             ← 선명도.  ⚠ 방향 확인 후에 켠다
     + λ_p · L_perc(지각 특징)                    ← §6-I 로 상관을 잰 뒤 고른다
     + λ_a · L_idm(자체 IDM, L1)                 ← Action 40% 유일 경로.  λ 0.01~0.05
   ```
3. **지각 손실 백본은 세 후보를 §6-I 로 비교해 고른다**: ① LPIPS(VGG), ② **무작위 초기화 VGG19**,
   ③ train 데이터로 우리가 짧게 학습한 특징. **무작위가 이기면 규정 위험이 0 이다.**
   ⚠ **VGG 계열 구조를 써라.** GoogleNet 은 픽셀 손실만보다 나빴다.
   ⚠ **무작위 특징을 평가 지표로는 쓰지 마라.** 지표로는 L2 수준이다.
4. **λ 를 크게 잡지 마라.** VP2 에서 LPIPS 가중 1 은 안전했고 **10 은 성공률을 반토막** 냈다.
5. **앙상블한다면 평균이 아니라 최악값 집계로.** 그리고 앙상블도 완전한 방어가 아니다.
6. **⭐ 조기 종료를 지금 설계에 넣어라.** ES-WMV(출력 이동창 분산 최소)는 정답 없이 작동한다.
   그리고 **손실에 안 들어간 축을 반드시 별도로 측정만이라도 하라** — 우리에겐 Action 40% 다.
7. **균형 알고리즘은 배제.** GradNorm 을 짧게 한 번 돌려 가중치를 뽑고 고정 가중합으로 박아라.
   구현은 VQGAN 방식이 가장 싸다 — **디코더 마지막 층 하나**의 gradient norm 비율.
8. **λ 탐색보다 학습률·정규화에 시간을 먼저 써라.**

## 5. 잔차 구조

**zero-init 은 마지막 층만.** [측정] CaiT ([2103.17239](https://arxiv.org/abs/2103.17239)) Table 1, ImageNet top-1:
12층에서 기준선 79.90 / **ReZero 78.3**(잔차 가지 전체를 스칼라 0 게이트 = **손해**) / Fixup 80.7 / **LayerScale 80.5**.
채널별 게이트(LayerScale)가 스칼라 게이트보다 12층 +2.2%p. 초기값은 **정확히 0 이 아니라 작은 양수**(ε=0.1).

**진짜 비용은 gradient 소멸이 아니라 지연이다.** [측정] ControlNet ([2302.05543](https://arxiv.org/abs/2302.05543)):
"abruptly succeeds... usually in **less than 10K optimization steps**" — 그림에서 약 6,133 스텝.

**잔차 유계화는 근거가 없다.** [측정] RIFE 는 Δ∈[−1,1] 로 묶지만 **4.5절 어블레이션에 잔차 범위 항목이 없다.**
RVD 는 아예 안 묶는다(σ=2 스케일만). ⇒ **tanh 를 기본값으로 넣지 마라.**
⚠ tanh 는 큰 움직임에서 gradient 를 죽여 **Action 40% 를 깎을 위험**이 있다.

**잔차 앵커링의 격리 어블레이션 — 017 이 "없다"고 한 것을 찾았다.**
[측정] RVD ([2203.09481](https://arxiv.org/abs/2203.09481)) Table 2, FVD(잔차 없음 → 있음):
KTH 1523→1351, BAIR 1374→1272, Cityscapes 1321→**997**.
[측정] TRIP ([2403.17005](https://arxiv.org/abs/2403.17005)): 지름길을 넣으면 FVD 39.9→38.9(2.5%)인데
**프레임 일관성은 95.92→96.41.** ⇒ [주장] **앵커링은 "품질"보다 "일관성"을 산다.**

**attention 은 병목에, 시간축은 (2+1)D 로.**
[측정] ADM ([2105.05233](https://arxiv.org/abs/2105.05233)) Table 1, ImageNet 128×128 ΔFID:
attention 을 16×16 한 곳 → 32/16/8 세 곳으로 늘리면 **−0.72**. 반면 BigGAN 리샘플로 바꾸면 **−1.20**.
⇒ **attention 해상도를 늘려 얻는 이득이 다른 구조 변경보다 작다.**
[측정] W.A.L.T ([2312.06662](https://arxiv.org/abs/2312.06662)): 윈도우 5×16×16 이 전역보다 FVD 55.3 vs 59.9 로 좋고 1.46배 빠르다.
[측정] R(2+1)D: 같은 파라미터로 R3D(61.8)보다 R(2+1)D(64.8)가 낫고 **학습 오차 자체가 더 낮다**(최적화가 쉽다).
그리고 **MC3(62.9) > rMC3(62.3)** — "시공간 모델링은 앞쪽(고해상도) 층에서 더 값을 한다".

**⭐ 구조 선택을 DINO/Video 만 보고 하지 마라.**
[측정] [1910.02564](https://arxiv.org/abs/1910.02564) — *BAIR 로봇, **행동 역추정 MAE 로 순위를 매긴다***:
SV2P 는 행동 R² 0.8719 로 **1위**인데 FVD 691.1 로 **3위**. SAVP-VAE 는 FVD 409.8 로 1위인데 행동 2위.
**품질 순위와 행동 순위가 실제로 뒤집힌다.**

### ⇒ 우리 설계에 주는 것

1. **zero-init 은 잔차 헤드 마지막 conv 하나만**(weight=0, bias=0). **ReZero 식 전체 게이트 금지.**
   게이트를 두려면 채널별 α 를 **작은 값(1e-3~1e-2)**으로.
2. **워밍업 지연 ~6,000 스텝을 예산에 반영해라.** 첫 1~2천 스텝만 잔차 헤드 LR 을 5~10배로.
   **잔차 norm 을 로깅해 언제 깨어나는지 눈으로 확인.**
3. **tanh 유계화를 기본값으로 쓰지 마라.** 무제한 + 채널별 α 가 기본.
4. **attention 은 1/16(20×32) 전용을 기본**, 1/8(40×64, 389ms)은 여유가 있으면. 쓴다면 **윈도우로.**
5. **시간축은 attention 이 아니라 (2+1)D 분해가 1순위.** 모든 해상도에 `1×3×3` 공간 conv +
   `3×1×1` 시간 conv(비용 저렴), attention 은 1/16 에만. 시간 conv 는 **항등 초기화**로 시작.
6. **⭐ 어떤 구조 변경이든 Action 성분을 따로 로깅해라.** "부드럽고 안정적인" 방향의 모든 선택
   (유계화, 큰 zero-init, 시간 정규화, MSE 가중)은 **DINO 를 올리면서 Action 을 깎을 위험**이 있다.

## 7. 찾지 못한 것 — 추측으로 메우지 않는다

**① 우리 지표로 잰 것이 0편이다.** DINOv2 CLS 코사인 + R3D 코사인 + 행동 MAE 로 어블레이션한 논문 없음.
가장 가까운 셋: CAPE(동결 DINOv2 ViT-S 384차원을 쓰지만 CLS 가 아니고 영상을 안 만든다),
Tora/MotionCtrl 의 TrajError(역추정 구조는 같지만 2D 궤적),
[1910.02564](https://arxiv.org/abs/1910.02564)(행동 역추정 MAE 를 쓰지만 64×64 BAIR).

**② 우리가 하려는 바로 그것의 전례가 없다.**
- **미분가능 IDM 보조손실을 생성 픽셀에 걸고 그 항만 켜고 끈 어블레이션 없음.** 실제로 그 배치를 한
  RLIR·EVA 는 전부 GRPO 보상(미분 불가), Vidar 는 추론 시 디코더였다.
- **"(a)백본 특징 위 IDM 으로 학습하고 (b)최종 픽셀로 평가했을 때 이전되나"** 를 측정한 논문 없음.
- **연속 6자유도 관절**에 대해 IDM 보조손실 on/off 를 역추정 MAE 로 잰 어블레이션 없음.
- IDM–생성기 공모(collusion) 현상에 붙은 **학술 용어가 없다.** 가장 가까운 것이
  EVA 의 "degenerate high-reward behaviors" 와 일반 RLHF 의 "reward hacking".
- 처방 중 **주기적 재학습 / 진짜+생성 혼합 / EMA 목표망**의 정량 근거를 각각 못 찾았다.
  정량 근거가 있는 것은 CoLA-World 의 warm-up 하나뿐이고 그마저 비지도 설정이다.

**③ 대리 손실 쪽.**
- **"LPIPS ↓ 가 DINOv2 CLS 코사인 ↓ 로 이어지나"를 직접 잰 논문 없음.** 반대 사례만 3건.
- **DINOv2 CLS 코사인 vs 흐림 σ 의 수치 곡선을 끝내 못 찾았다.** 017 이 못 찾은 이유가 있다 —
  **아마 존재하지 않는다.** 우리 실측이 사실상 유일한 자료다.
- **R3D-18 특징 코사인 거리 vs 흐림/해상도 곡선 없음.** Video 30% 에 대한 외부 근거는 0.
- 진짜 목표가 우리처럼 **고정된 결정론적 합성 함수**인 과최적화 연구 없음
  (확인한 것은 전부 사람 평가 / 더 큰 골드 보상모델 / 인공 난수 보상).

- **후처리 샤프닝이 특징 거리를 개선했다는 정량 사례 없음.**

**④ 구조 세부.**
- **잔차 유계화(tanh vs clamp vs 무제한) A/B 없음.**
- **"attention 을 1/16 에만 vs 1/8 까지"** 격리 어블레이션 없음.
- **잔차 헤드에 학습 가능한 스케일 게이트**를 둔 것의 격리 어블레이션 없음(영상 예측 맥락).
- **320×512 급에서 16프레임 잔차 예측의 비용 수치 없음.** 조사한 논문은 64~256px 에 몰려 있다.
  ⇒ 우리 실측(1/8 389ms, 1/4 6,238ms)이 유일하다.
