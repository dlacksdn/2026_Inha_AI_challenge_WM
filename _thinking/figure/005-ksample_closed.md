# 005 ⭐ — 평균내기 노선 폐쇄, 그리고 두 지표가 정반대를 가리킨 사건 (2026-08-01 20:40)

> 결정: **확산모델 샘플을 평균내는 길을 닫는다. 그리고 C 를 픽셀 L1 만으로 학습하면 안 된다.**

## 왜 시도했나

문헌 조사에서 희망을 찾았다. 우리와 거의 같은 대회
(**1X World Model Challenge** — 휴머노이드 로봇, 행동조건, 단일 정답 채점)의
우승팀이 **확산모델을 버리지 않았다.** 샘플 20개를 픽셀공간에서 평균내
PSNR 22.63 → 24.88 (+2.25dB) 를 얻었다. K=1→5 만으로 이득의 84%.

**016 §9.1 은 branch B 의 *학습* 을 동결했지 추론까지 동결한 것은 아니다.**
체크포인트·생성 배선·제출 파이프라인이 전부 살아 있다.
즉 **학습 없이, 이미 가진 자산으로** 점수를 개선할 수 있는지가 질문이었다.

우리 생성 설정을 확인하니 이미 유리했다 — `unconditional_guidance_scale: 1.0`(CFG 꺼짐,
1X 가 켜면 −0.68dB 라 보고한 항목), `ddim_eta: 0.0`(결정론).
**샘플이 달라지는 유일한 원천은 초기 노이즈**이므로 seed 만 바꾸면 된다.

## 1단계 — 전제조건: 오차가 분산인가 편향인가 (픽셀 기준, n=96)

**평균은 흔들림(분산)을 지우지 치우침(편향)을 못 고친다.** 먼저 그걸 갈랐다.

```
  pred_k = 정답 + 편향 + 잡음_k  라 두면
    한 장의 오차    = |편향 + 잡음|
    K장 평균의 오차 = |편향 + 잡음/K|     ← 잡음만 줄어든다
  ⇒ K장 평균이 한 장보다 확실히 작으면 **분산이 지배한다**
```

```
평균내기의 전제조건 (n=96, 픽셀 L1, 255 스케일, K=3)
------------------------------------------------------------------------------
  정지영상의 오차            8.498    ← 넘어야 할 선
  샘플 한 장의 오차         12.343
  **세 장 평균의 오차**     11.054    (−10.4%)

  샘플 간 흔들림(표준편차)   7.969
  맞혀야 할 변화량           8.498
  흔들림/변화량              0.938     ← 흔들림이 변화량과 맞먹는다

  짝지은 비교 (평균 − 한장)  Δ=−1.2894  SE=0.0984  **t=−13.11  승 96/96**
------------------------------------------------------------------------------
  → **평균이 픽셀 오차를 유의하게 줄인다. 분산이 지배한다.**
  → 정지영상 대비: 평균 11.054 vs 정지 8.498 (나쁘다)
```

**96표본 전부에서 평균이 낫다. 예외가 하나도 없다.**
전제조건은 충족된 것처럼 보였다.

## 2단계 — 채점 기준으로 재니 **정반대**였다 (n=96, K=5)

seed 0~4 로 홀드아웃 96 을 다섯 벌 생성해 실제 채점기로 쟀다.

## ⭐ 이게 오늘 가장 중요한 교훈일 수 있다

```
  같은 영상, 같은 96표본

    픽셀 L1     12.343 → 11.054   **−10.4% 개선.  96/96 전부 개선**
    채점 DV      0.0943 →  0.1132  **+20% 악화.   t=+9.99**
```

016 §5 는 **로컬과 eval** 이 방향까지 어긋난 전례를 남겼다.
이번엔 **로컬 안에서** 픽셀 지표와 채점 지표가 정반대로 갔다.

> **대리 지표는 크기뿐 아니라 방향조차 믿을 수 없다.**

### 왜 이런 일이 — 이론이 예고한 함정이 그대로 나타났다

문헌 조사에서 코사인 거리도 "평균이 유리"함을 유도하면서 **함정 하나를 적어 뒀었다**
(017 §3.3):

> ⚠ 최적해 `m/‖m‖` 를 실제로 **만들어낼 수 있어야** 한다.
> DINOv2 특징공간에서 실제 이미지들이 차지하는 영역은 얇은 곡면이라
> 평균 방향이 그 곡면 위에 있다는 보장이 없다.

**그 함정이 이것이다. 픽셀공간의 평균은 특징공간의 평균이 아니다.**
픽셀을 평균내면 특징공간에서 **곡면을 벗어난 흐릿한 점**으로 가고, DINOv2 가 심하게 벌한다.
[004](./004-blur_budget.md) 의 흐림 예산(σ ≈ 1.2~1.9px)과도 맞물린다 —
샘플끼리 평균 10픽셀씩 어긋나는데 평균내면 예산을 한참 넘는다.

### 1X WMC 결과가 왜 이전되지 않았나

```
  1X World Model Challenge   채점 = **PSNR** (픽셀 지표)        →  평균이 +2.25dB
  우리                       채점 = 60% 특징 거리 + 40% Action  →  평균이 손해
```

**세팅이 비슷하다고 지표가 같은 것은 아니다.**
문헌이 준 것을 우리 데이터로 확인하기 전에는 쓰면 안 된다.

## ⇒ C 설계에 주는 것 (중요)

1. **평균내기 노선을 닫는다.** branch B 는 학습 동결에 이어 **추론 재활용 경로도 닫혔다.**
2. ⚠ **C 를 픽셀 L1 만으로 학습하면 안 된다.** 결정론 회귀가 L1 로 만드는 출력이
   바로 **조건부 평균**이고, 이 측정이 보여준 것은 **조건부 평균이 우리 채점에서
   벌받는다**는 것이다.
3. **⇒ 채점기를 직접 손실로 쓸 근거가 크게 강해졌다.**
   픽셀공간의 최적점과 특징공간의 최적점이 **우리 데이터에서 실제로 다름을 확인했다.**
   픽셀 항은 **붕괴를 막는 닻**으로 두고, **최적화의 주도권은 채점기 손실
   (DINOv2 CLS + action extractor)에 준다.**

## 부수 — 인코딩 틈은 무시해도 된다
