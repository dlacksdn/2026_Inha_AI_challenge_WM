## 2. 08-11 첫 점을 어떻게 읽나

```
43,500(수정) λ=0.2   0.2888
11,000(구)   λ=0.15  0.2876      차이 +0.0012 (인코딩 잡음 ±0.0004 의 3배)
```

**결론을 내지 않는다.** 이 두 점은 **체크포인트와 λ 가 동시에 다르다.** 두 축이 뒤엉킨다.

**G11 은 미판정이다** — 같은 체크포인트에서 λ 를 비교하는 판정인데 43,500 에 점이 하나뿐이다.
남은 둘(`lam0.15_step043500.csv` · `lam0.25_step043500.csv`)이 들어와야 판정된다.

λ 의 무게는 이미 실측돼 있다: step 11,000 에서 λ 0.1~0.25 사이 점수가 **0.0199** 흔들렸다.
정지영상을 넘은 폭(0.0157)보다 크다. **0.15 나 0.25 가 최고를 넘을 여지가 있다.**

### 다만 기록해 둔다 `[측정]`

```
감시 코사인   0.53 (구, 14,500스텝 정체)  →  0.618 (수정, 43,500)
리더보드      0.2876 (최고)               →  0.2888 (아직 못 넘음)
```

**코사인이 크게 올랐는데 점수는 최고를 못 넘었다.** 로컬 지표가 리더보드를 예측하지 못한
사례가 하나 더 늘었다 — 단, λ 를 완전히 재보기 전엔 단정하지 않는다.
