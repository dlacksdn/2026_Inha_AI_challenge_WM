## 1. ⭐ 팀 분업 구조 — 이게 목표선을 정한다 (어디에도 없던 정보)

```
팀메이트  DynamiCrafter(잠재 확산) 노선.  리더보드 0.25 기록 (8/3 초기화 **이후**)
우리      잔차 회귀(C) 노선.  분업하기로 합의했다
```

**왜 중요한가 — 세 가지가 여기서 따라 나온다.**

**① 목표선이 0.30325 가 아니라 0.25 다.**
최종 채점은 **팀이 고른 파일 1개**로만 된다(rule/001 §4.2).
우리가 0.25 를 못 넘으면 **C 의 팀 기여는 0** 이다.

**② 018 §9.2-c 가 잔차를 고른 원래 이유가 약해졌다.**
그 논변은 *"실패해도 정지영상(0.30325)으로 폴백하니 손해 0"* 이었다.
**팀 최고가 0.25 인 지금, static 폴백은 값어치가 거의 없다.**
(005 가 이 모순을 지적했다. 새 근거를 세우거나 노선 근거를 다시 써야 한다.)

**③ 서둘러서 얻는 게 없다.**
B 가 바닥을 깔고 있으므로 급조한 C 가 0.28 을 내는 것은 무의미하다.
**얇고 빠른 v1 보다 제대로 된 한 번이 낫다.**

### 1-b. 팀메이트에게 들은 노하우 (검증 안 됨. 그러나 같은 대회·같은 채점기다)

> **"먼저 시각을 안정시키고 그 다음에 action 을 학습시키니 잘 되더라.**
> **로스에 뭘 추가하냐로 뭘 학습시키냐를 조정한 듯 보였다."**

⚠ **그대로 복사하지 마라. 우리와 구조가 다르다.**

| 축 | 팀메이트 (잠재 확산) | **우리 (픽셀 잔차 회귀)** |
|---|---|---|
| step 0 출력 | 노이즈에서 복원 → 불안정 | **정확히 첫 프레임.** "시각 안정화" 단계가 할 일이 없다 |
| 손실 부착 | 출력이 latent → 픽셀 손실에 VAE 디코드 필요(비싸다) | 출력이 곧 픽셀. 공짜 |
| 학습 신호 | 매 스텝 (t, ε) 추첨 → 확률적 | 결정론적 |

**[추측] 그 사람의 단계 분리는 학습 원리가 아니라 latent 구조가 강제한 비용 우회일 수 있다.**
우리는 그 제약이 없으므로 **처음부터 세 항을 걸고, gradient 코사인이 음수로 지속되면
그때 단계로 분리**하는 편이 맞다(018 §8.2 의 처방). 순서를 미리 못 박지 말고 **측정으로 정하라.**

> ⚠ 다만 그 사람이 쓴 action 손실이 **킷의 action_extractor 였다면 지금은 규정 위반**이다
> (rule/001 §12·§13). 우리가 따라 할 수 없는 경로다. 자체 IDM 을 외부 문헌만으로 설계해야 한다.

### 2-b. ✅ 닫힌 것 — "킷 관련은 전부 공개 안 된 것으로 취급한다"

한동안 *"DINOv2·R3D 는 킷에 없는 공개 가중치이니 직접 받아 쓰면 되지 않나"* 를 회색으로 두고
주최 질의를 준비했다. **그 해석을 폐기했다.** (rule/001 §13.4)

```
❌ 하지 않는다   킷이 쓰는 모델을 알아내 손실에 넣기 / 전처리를 재현해 자체 채점기 만들기
                로컬에서 점수를 흉내 내 체크포인트 고르기 / 이에 대한 주최 질의
✅ 한다          공개 문헌에서 고른 손실로 학습 (픽셀 L1 · 주파수 손실 · 자체 IDM)
                판정은 리더보드로만 (하루 10회)
```

> **왜**: 017 §5.2 가 회색지대를 우리에게 유리한 쪽으로 확정 승격했다가 틀렸다.
> **규칙 해석에서 유리한 쪽을 고르지 않는다.** 이게 이 프로젝트의 규율이다.
>
> ⚠ 그러므로 **"배점 60% 를 로컬에서 되찾는다"는 계산은 폐기됐다.**
> 리더보드 하루 10회가 처음부터 끝까지 유일한 계기판이다.

### 4-2. git push 가 "Everything up-to-date" 로 나온 진짜 이유

**토큰 문제가 아니었다.** `_thinking/residual` → `residual_plan` **폴더 이름 변경이 커밋되지 않아서**
001~004 가 전부 git 밖에 있었다. 인증은 성공했고 올릴 게 없었을 뿐이다.

> **처방: push 전에 반드시 `git status --short` 를 본다.**
> `??`(추적 안 됨)나 ` D `(삭제됨)로 시작하는 줄이 있으면 아직 커밋 안 된 것이다.

### 4-3. 셸 cwd 가 상위로 리셋된다 (018 §운영 2번 재확인)
