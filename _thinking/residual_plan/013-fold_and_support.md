## 1. 012 검수 — 두 결론 다 유지한다. 표현 하나만 정정

### 1-a. "정지영상을 이기는 λ 가 없다" — **맞다**

| 무엇을 확인했나 | 결과 | 등급 |
|---|---|---|
| λ 3점(0 / 0.25 / 0.5)의 2차 피팅 | 독립 재계산 일치: 최소점 λ=0.0278, 이득 0.00025 < 잡음 ±0.0004 | [측정] |
| λ=0 mp4 = 정지영상 md5 | **재계산 6/6 일치** (736acd… 등). 별도 추론런끼리도 8/8 일치 | [측정] |
| 제출 경로 보존율 1.000 | `native_cosine_20260810_0418.json` 원값 확인 (0.5487→0.5489) | [코드] |
| S₀ = 참조값 1e-6 차이 | 007·019·004 에 독립 기록된 0.30325 와 대조 | [문서] |

핵심: 이 결론은 2차 피팅에 기대지 않는다. **008 §9-b 가 결과 보기 전에 등록한 판정표**
— *"λ 커질수록 나빠짐 → A-1. 손실·구조를 바꾼다"* — 가 단조성만으로 발동한다 [문서].
한계: 리더보드는 λ≤0.5 까지만 쟀다. 0.5~1.0 은 안 쟀지만 손해가 λ² 로 커지는 실측 +
픽셀 눈금(λ=1 은 정지영상보다 42% 나쁨, env_file/004 §4)이라 제출로 확인할 가치가 없다.
리더보드 숫자 자체는 저장소 밖(웹)이라 독립 검증 불가 — 내부 정합성만 확인했다.

### 1-b. "코사인 0.55 가 값어치 없다" — **결론 유지, 표현 정정**

정확한 문장은 이것이다: **코사인 0.55 가 손해라는 것은 동결 지도(008 §5)가 이미 예측했었다**
(본전 = 0.95). 놀란 것은 방향이 아니라 크기다 — 실측 손해 +0.073 이 지도 예측(+0.018 @0.71)의
3~4배다. 즉 Goodhart 가 "터졌다"기보다 **"지도대로, 지도보다 더 나쁘게"** 다.
대안 설명은 전부 실측으로 소거됐다: 배선(md5) · 경로(보존율 1.000) · 채점 변경(S₀ 1e-6) [측정].

부수 정정 하나: Δcos 오름(0.044→0.128)은 경보가 아니다. `train_c.py:120-129` 실코드 확인 —
Δcos = 홀드아웃 코사인 − 뒤섞기 코사인, 즉 **행동 기여 마진**이고 오르는 게 정상 방향이다 [코드].
012 의 읽기("행동 경로는 강해지는데 총 코사인이 안 오른다")가 정확하다.

### 1-c. 012 가 안 적은 결정적 산술 — 이게 판단을 확정한다

008 §8-① 에 이미 적혀 있었다: 018 오라클이 이 노선 계열에 약속한 **최상** 시나리오
("첫 프레임 + 그럴듯한 모션, 1/2 해상도")가 **−0.038, 즉 약 0.265** 다 [문서].

## 2. 판단 — C. 근거

### 2-a. 왜 A(계속)가 아닌가 — "0.52 평평이 깨진다"는 근거가 없다

| 실측 | 값 | 등급 |
|---|---|---|
| 코사인, 최근 3,500스텝 | 평균 0.5226 · σ 0.0036. 완전히 평평 (history.json 재계산) | [측정] |
| 잔상 세기, 8,000스텝 | 0.43~0.73 정체. 1.0 으로 안 감 | [측정] |
| 방향코사인 | 0.22(8.5k)~0.32(15k) 요동. 판정선 0.5 미달 | [측정] |
| 행동→방향 신호 | R² 0.6% · L1 기여 0.3%. **배울 신호가 이 크기다** | [측정] |
| 등록된 눈금 | 016 §7: "1,000스텝에 유의 개선 없으면 남은 날에도 없다" | [문서] |

필요 코사인 0.95~0.96 (008 §5 격자 + 009 §1 눈금, 독립 유도 둘) vs 현재 0.52.
16,600 스텝이 만든 전부(0→0.52)보다 큰 도약이 필요하다. 그것이 일어날 근거가 위 표에 없다.

### 2-b. 왜 B(구조 변경)가 아닌가 — 시간이 아니라 기전이 안 맞는다

후보는 재앵커링 하나다(004 §7 예비책, 미구현) [문서]. 산술:

```
구현 0.5~1일 + 재학습 30k×5.05s ≈ 42h + 스윕 제출  →  첫 리더보드 판정 최속 8/13 = 사망선 당일
반복 기회 0회.  한 방에 코사인 0.52 → 0.95 도약이 나와야 한다
```

그리고 기전이 틀렸다: 재앵커링이 고치는 병리는 "잔차가 자라며 잔상이 쌓임"이다.
실측된 병리는 **"방향이 무작위"** (0.22~0.32)이고, 그 원인은 신호 부재(R² 0.6%)다.
앵커를 옮겨도 방향 신호는 생기지 않는다 [추측 — 단, 모든 실측과 정합].
성공해도 §1-c 에 막힌다: 0.25 를 못 넘는다.

### 2-c. 왜 C 인가 — 등록된 판정선들이 이미 같은 방향이고, 지원에 내용이 생겼다

**C 는 새 판단이 아니라 등록된 판정선들의 조기 집행이다:**

```

008 §8-① 사망선  8/13 까지 S₀ 를 넘어야 함 → 넘을 수단이 없음이 실측됨 (§2-a·b)
⇒ 8/13 까지 기다리는 것은 이미 아는 답에 3일을 내는 것이다. 그 3일이 재현 리허설 창이다
```

**지원의 내용 — 팀의 진짜 위험은 0.25 의 재현이다:**

1. **0.25 는 검증 기록이 0인 구두 수치다.** 005 §중-5 가 지적하고 검증 과제(팀 제출탭 확인 +
   3질문)를 등록했는데 **아무도 실행하지 않았다** [문서].
2. 수상권이면 **8/21 14:00 까지**(종료 후 20시간) Private 재현 코드 제출. 기준 하드웨어가
   정확히 이 기계다: RTX PRO 6000 1대, 학습 ≤4일, **추론 ≤1시간** [문서 rule §3.3].
3. 저장소 실측이 초과를 가리킨다: DynamiCrafter급 추론이 5090 에서 94분(제한 34분 초과),

   느리다**(596 vs 551 ms/micro-step) [측정 011 §2]. **0.25 가 재현 불가면 팀 점수가 아니다.**
4. 우리가 가진 것이 정확히 그 검증 도구다: 기준 하드웨어(GPU 0) + 검증된 제출 배선
