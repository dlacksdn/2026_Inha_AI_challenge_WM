## 2. 005의 약점 셋

### 2-1. 무유도 수치를 무유도 수치로 갈아끼웠다

005의 대표 공격은 치-1 *"ρ<0.2는 신설 무유도 수치다"*인데, 005가 새로 박은 판정선은:

```
유도 있음 2개   S₀±0.001 (mp4 흔들림 ±0.0004 의 2.5배) · δ≈0.011 (2·SE·√(96/65))
유도 없음 8개   Δcos≥0.02 · t≥+2 · wake=5% · G2=wake+4,000 · 16표본 · 5점스윕
               · 보조항=L1의 25% · 잔차코사인 0.7 연속 2회
```

**무효화 사유는 아니다** — 결과를 보기 전에 박은 숫자는 근거가 없어도 규율 1을 지킨다.
다만 **"유도"가 아니라 "관례(convention)"로 라벨해야** 같은 공격이 재귀하지 않는다.

### 2-2. 목표 산술이 설정 간 환산이다 (규율 6 위반)

005 치-4: *"필요 개선 0.0533 = 로컬 오라클 천장(−0.0712)의 75% = 1/2해상도 천장의 140%(도달 불가)"*

**이 비교는 성립하지 않는다.** [측정] 018 원문 확인:

```
로컬 홀드아웃   static 0.56032   정답영상 0.48911   → 천장 0.07121
eval 리더보드   static 0.30325   정답영상 미지
```

**eval의 static(0.30325)이 로컬의 정답영상(0.48911)보다 낮다.** 절대 스케일이 다르다
(로컬 Action 1.24 vs eval 0.43). 여기서 eval 요구량을 로컬 천장으로 나누는 것은
자로 잰 길이를 저울에 올리는 것이다.

005는 올바른 수치를 손에 쥐고 있었다 — 같은 문단에 *"eval DV 헤드룸은 로컬의 2.05배"*라 써놓고
결론은 환산하지 않은 쪽("닫혀 있다")으로 냈다. **005가 004에게 쓴 표현 그대로 — 선택적 읽기다.**

### 2-3. 단일점에서 일반화했다 (003 치-3의 재발)

005 §0은 `N_S=4 · b1` 한 점에서 *"bf16 절감 ~10%뿐"*을 얻어 전역 명제로 썼다.
[측정] 실제로는 **N_S=4 b1 13.6% · N_S=4 b2 21.2% · N_S=2 b1 31.9%** — 설정 의존이다.
그리고 §0은 내부 모순이다: "10%뿐"이라 써놓고 "bf16은 배치를 만드는 필요조건"이라 처방한다.

> **다만 005 §0의 수치 자체는 재현된다** (§4 표 참조). 남는 지적은 수치가 아니라 절차다 —

## 3. ⭐ 목표 산술을 무차원으로 다시 세운다

절대 델타는 설정을 건너뛸 수 없다. **비율은 그나마 건널 가능성이 있다.**

[측정] 016 §4.3의 검증된 eval 성분분해 위에서:

```
eval static:  DV_raw = 0.43916,  Action = 0.42874
              0.3×0.43916 + 0.4×0.42874 = 0.30324   ← 리더보드 실측 0.30325 과 일치 ✅

목표 0.25  →  DV_raw ≤ 0.26168  →  static 대비 DV 를 40.4% 줄여야 한다
민감도     →  Action 이 016 확산모델만큼 악화되면 51.8%
```

**⇒ "0.25 미만"의 정확한 의미: eval DINO+Video 코사인 거리를 40.4% 줄이는 것.**
Action(배점 40%, eval static 점수의 57%)은 우리가 못 건드린다고 보는 것이 016 §5의 교훈이다.

⚠ **가정 명시**: ① Action 불변 ② 로컬→eval 의 *비율* 이송. 둘 다 [추측]이다.
016 §5는 로컬과 eval이 **방향까지** 어긋난 전례를 기록했다. 첫 제출에서 실측·갱신해야 한다.

## 4. ⭐ 그래서 004의 N_S=4~6은 목표를 배제한다

같은 018 오라클을 **DV 감축률**로 다시 읽는다 (로컬 Action은 016 §5가 폐기 선언):

| 잔차 유효 해상도 | 004가 인용한 값(ΔTOTAL) | **실제 DV 감축률** | 3라운드 독립구현 |
|---|---:|---:|---:|
| 1/2 (160×256) | −0.038 | **48.3%** | 56.0% |
| **1/4 (80×128)** | −0.017 | **16.1%** | **2.1%** |
| **1/8 (40×64)** | −0.004 | **−1.8% (static보다 나쁨)** | — |
| 1/16 | −0.0004 | −9.3% | — |
| **필요량** | | **40.4%** | |

**004 §2.3 ④는 N_S=4~6, 즉 1/4~1/8을 골랐다. 방향이 완벽한 오라클로도 16.1% ~ −1.8%다.**

왜 004가 못 봤나 — **폐기 선언된 성분이 만든 착시를 옮겨 적었기 때문**이다. 018:754가 이미 못 박아 뒀다:

> **⇒ 오라클 잔차의 하방은 0이 아니라 DV 기준 +0.006(손해)이다.**
> "0으로 막혀 있다"는 그림은 신뢰하지 않기로 한 성분이 만든 착시다.

그리고 018 확증 3(018:1163)은 **"DV를 최적화 대상으로. 로컬 Action 값으로는 어떤 판단도 하지 않는다"** — 확증 등급이다.

**005는 이 사실을 봤다** (§3-2 경미: *"1/16은 DV 기준 +0.006 손해… 각주로"*).
**각주로 달 일이 아니었다.** 한 걸음 더 갔으면 이 절의 결론이 나왔다.

### 4-b. 코드가 같은 말을 한다

[코드] `simvp_model.py:22,51-54` — `sampling_generator(N_S)=[False,True]*(N_S//2)`, 다운샘플 횟수 = `N_S//2`
⇒ **1/2 해상도를 얻으려면 N_S=2다.**

[코드] OpenSTL 공식 TAU config:

```
bair         (로봇 조작)      N_S = 2   ← 우리와 가장 가까운 도메인
kitticaltech (주행 실사)      N_S = 2
taxibj                       N_S = 2
kinetics     (자연 영상)      N_S = 4
mmnist       (64×64 흑백)     N_S = 4
```

**로봇·실사 계열은 전부 N_S=2다.** 004의 선택은 목표 산술과도, 베이스 자신의 참조 설정과도 어긋난다.

⚠ **한계**: "뭉갠 잔차"가 실제 디코더 출력의 대리값이라는 가정 위에 있고,
018 §9-d F가 그 가정에 **20.52% 민감도** 경고를 붙였다. 스킵 연결이 있는 디코더는 저역통과보다 나을 수 있다.
⇒ 주장은 *"N_S=4는 확실히 실패한다"*가 아니라 **"이 어긋남을 해소하지 않고 동결하면 안 된다"**이다.

## 8-b. ⚠ 이 문서의 산술이 딛고 있는 것 — 사용자 판단이 필요하다

§3·§4 의 목표 산술은 **킷으로 만든 수치** 위에 있다.

```
0.30325            리더보드 실측.  공개 정보다.  문제 없다
0.3D+0.3V+0.4A     대회 페이지 §3.1 공개 산식.   문제 없다

018 오라클 표       로컬 채점기(src/wm_eval/scoring.py) 산출물
```

**두 규정이 서로 다른 방향을 가리킨다.**

| | 무엇이라 하나 |
|---|---|
| rule/001 **§13.3** | *"013~018 이 만든 오라클 지도는 **그대로 쓰되 갱신할 수 없다**"* → 사용 가능 |
| rule/001 **§13.4** (더 최신) | *"산식이 어떤지 — 전부 모르는 것으로 놓는다"* → 더 좁게 읽으면 이 산술도 대상 |

**내 입장**: §13.3 이 명시적으로 보존한 범위 안이고, 산술은 *학습·추론·출력 선택에 전혀 들어가지 않는다*
(아키텍처 하이퍼파라미터 하나를 고르는 데만 쓴다). 그러나 §13.4 의 원칙이
*"규칙 해석에서 우리에게 유리한 쪽을 고르지 않는다"* 이므로 **내가 단독으로 정하지 않는다.**

> **⭐ 다행히 결론은 이 산술 없이도 선다.**
> N_S=2 는 **킷과 무관한 외부 근거**로 독립 지지된다 — OpenSTL 공식 config 가
> 로봇(bair)·실사(kitticaltech)·taxibj 에서 전부 N_S=2 다(§4-b, [코드]).
> 산술을 통째로 버려도 **N_S=2 채택은 살아남는다.** 잃는 것은 "왜 40.4% 인가"라는 눈금뿐이다.
