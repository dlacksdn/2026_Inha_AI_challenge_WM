## 0. 한 줄

> **잔차를 더하면 점수가 나빠진다.** 정지영상 0.3032 · λ=0.25 → 0.3192 · λ=0.5 → 0.3762.
> 배선도 경로도 멀쩡하다. **로컬 코사인 0.55 가 이 채점기에서 값어치가 없는 것이다.**

---

## 1. ⭐ 리더보드 3회 — 이게 이 문서의 전부다

| λ | 리더보드 | 정지영상 대비 |
|---:|---:|---:|
| **0** | **0.3032489418** | 기준점 |
| 0.25 | 0.3191941717 | **+0.0159 손해** |
| 0.5 | 0.3761603675 | **+0.0729 손해** |

```
손해가 λ² 에 거의 정확히 비례한다 (0.0729 ÷ 0.0159 = 4.58 ≈ 4)
2차식으로 맞추면 최소점 λ ≈ 0.03, 그때 이득 0.0003
  ← mp4 인코딩 흔들림(±0.0004, 003 경-1)보다 작다
```

**⇒ 정지영상을 이기는 λ 가 존재하지 않는다.** 008 §9-b 가 등록한 판정표의
*"λ 커질수록 나빠짐 → **A-1** 이다. 손실·구조를 바꾼다"* 에 해당한다.

---

## 2. 그 답을 믿어도 되는 이유 — 배선과 경로를 먼저 증명했다

### 2-a. G3 통과 — 배선 정상 `[측정]`

λ=0 mp4 가 정지영상 mp4 와 **md5 까지 완전 일치**한다(표본 6/6). 제출해 보니
**0.3032489418** 로 참조값 0.30325 와 **1e-6** 차이다.

```
⇒ 모델 → mp4 → 킷 → CSV → 리더보드 전 구간 정상
⇒ eval 집합·채점식이 안 바뀌었다.  008 §8-③ M1 의 "0.30325 를 벗어나면 007 §3 산술과
   A-1/A-2 표를 전부 폐기하라" 조건이 **발동하지 않는다.** 그 지도는 계속 쓸 수 있다
```

### 2-b. 제출 경로에서 잔차가 안 샌다 `[측정]`

009 §2 가 남긴 걱정 — 감시는 **320×512 모델 공간**에서 재는데 채점은 **640×480 mp4** 다.
그 왕복을 아무도 안 쟀다. 쟀다(`probe_native_cosine.py`, n=16):

```
① 모델 공간 320×512        +0.5487   ← 감시가 재는 것
② native 640×480 (mp4 전)  +0.5417
③ native 640×480 (mp4 후)  +0.5489   ← 실제 채점되는 것
전체 보존율 1.000
```

**해상도 왕복도 x264 도 코사인을 안 깎는다.**

### 2-c. ⇒ 남은 설명은 하나

**코사인 0.55 가 이 채점기에서 값어치가 없다.** 흐려짐의 벌점이 방향이 절반 맞아 얻는 이득보다 크다.
010 §2-③ 이 *"감수하는 위험"* 이라 적어 둔 Goodhart 가 실제로 터졌다.

### 2-d. 손익분기가 어디인지는 이미 적혀 있었다 `[문서]`

008 §5 의 A-1 격자:

```
A-1 α=0.75  코사인 0.95  →  본전
A-1 α=0.50  코사인 0.71  →  +0.018 손해
우리        코사인 0.55  →  실측 +0.073 손해 (λ=0.5).  격자 예측보다도 나쁘다
```

**본전을 맞추려면 코사인 0.95 가 필요하다.** 009 §1 의 눈금(필요 0.96)과 같은 숫자다.

## 3. 코사인은 0.52 에서 멈췄고, 잔상은 학습으로 안 사라진다 `[측정]`

### 궤적 (긴 런, step 5,500~16,500)

| step | 코사인 | 뒤섞기 | Δcos |
|---:|---:|---:|---:|
| 6000 | +0.457 | +0.412 | +0.044 |
| 10000 | +0.512 | +0.427 | +0.085 |
| 13000 | +0.524 | +0.395 | +0.129 |
| 15000 | +0.515 | +0.395 | +0.120 |
| 16500 | +0.523 | +0.395 | +0.128 |

```
최근 3,500 스텝 코사인 평균 0.52 · 표준편차 0.004.  완전히 평평하다
Δcos 는 계속 오른다 (0.044 → 0.128, 문턱 0.046 의 2.8배)
```

**행동 경로는 살아 있고 계속 강해지는데 코사인 총량이 안 오른다.**

### 잔상의 정체 — 세기가 0.6 에서 멈춘다

`probe_erase_vs_draw.py` 로 체크포인트 5개를 쟀다. `amp` = 필요한 세기 대비 실제 낸 세기.

| step | 지우는 곳 amp⁻ | 그리는 곳 amp⁺ |
|---:|---:|---:|
| 7000 | 0.499 | **0.729** |
| 11000 | 0.433 | 0.539 |
| 15000 | 0.522 | 0.639 |

**8,000 스텝 동안 0.5~0.7 에서 오르내리기만 한다. 1.0 쪽으로 가지 않는다.**
⇒ 잔상은 덜 학습돼서가 아니다. **더 돌려도 안 사라진다.**

`[추측]` 원인: 팔이 정확히 어디로 갈지 모르면 L1 의 최적 답이 "가능한 위치들의 평균"이고,
그 평균이 화면에서 반투명 잔상이다. 008 §4 가 이미 잰 것 — 행동이 움직임 방향을 설명하는
비율은 **R² 0.6%** 이고 L1 을 0.3% 밖에 못 줄인다.

## 4. ⚠ 이 세션이 세웠다가 반증한 가설 셋

전부 **판정선을 결과 보기 전에 박고** 쟀다. 다음 세션이 같은 길을 다시 파지 않도록 남긴다.

| # | 가설 | 판정선 | 결과 |
|---|---|---|---|
| ① | **"지우기는 잘하고 그리기를 못한다"** | cos⁻−cos⁺ ≥ 0.10 AND amp⁻/amp⁺ ≥ 1.5 | ❌ **반대였다.** cos⁻ +0.33 < cos⁺ +0.58 |
| ② | **"불투명도 50~65% 로 움직인다"** | 이동비 ≥ 0.5 AND 방향코사인 ≥ 0.5 | ❌ **이동비 0.74 인데 방향코사인 0.32.** 엉뚱한 쪽으로 간다 |
| ③ | **"제출 경로에서 신호가 샌다"** | ③ ≥ ① × 0.8 | ❌ 보존율 1.000. 경로는 멀쩡하다 |

②가 중요하다. **사용자가 영상을 보고 "투명해지기만 하고 이동을 안 한다"고 지적한 것이 맞았다.**
①의 근거(cos⁺ > cos⁻)에 구멍이 있었다 — 옛 자리를 뭉개기만 해도 가장자리에 양(+) 잔차가 생겨
cos⁺ 가 올라간다. **잔차 부호만으로 "새 자리에 그렸다"를 주장하면 안 된다.**

## 8. 아직 모르는 것 (추측으로 메우지 마라)

1. **어느 성분이 깎였나** — 리더보드는 총점 하나만 준다. DINO 인지 Action 인지 모른다.
   `[추측]` 정지영상은 행동을 0 으로 추정당하는데, 틀린 움직임은 틀린 행동으로 추정당해
   Action(배점 40%)이 더 나빠질 수 있다. **확인 수단이 없다** (로컬 채점 봉인, rule §13)
2. **코사인 0.95 에 도달할 길이 있나** — 현재 0.52 에서 3,500 스텝째 평평
3. **재앵커링이 답인가** — 003 치-2 가 지목하고 004 §7-3 이 예비책으로 등록한 것.
   우리가 잔차 식을 빌려온 논문이 **이 병리를 진단하고 앵커를 버렸다.** 미구현·미검증
4. **주파수 손실을 켜면** — G2.5 조건은 충족. 그러나 004 §3 이 *"방향이 틀린 채 선명하게
   하면 틀린 움직임이 더 선명해질 뿐"* 이라 경고했고, **A-1 이 확인된 지금 그 경고가 정확히 적용된다**
5. **남은 19시간(step 30,000까지)이 무엇을 사는가** — 코사인이 올라도 점수로 안 이어진다는 것이
   실측됐다. 계속할 근거가 약하다
