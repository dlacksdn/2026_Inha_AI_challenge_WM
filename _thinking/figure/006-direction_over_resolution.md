# 006 ⭐ — 해상도는 목표가 아니라 **방향 정확도의 증폭기** (2026-08-01 21:06)

> 결정: **C 설계서의 1순위 질문이 "해상도를 어떻게 확보하나"에서
> "방향을 어떻게 맞히나"로 바뀐다.**
> 상세 서술: [018 §9-d](../model_select/018-warp_vs_add_verdict.md)
> 원자료: `results/branchC/round3.json`

## 왜 쟀나 — 십자가만 재고 가운데를 안 쟀다

2차 적대적 검수의 가장 날카로운 지적이었다.

> 모든 측정이 *(방향 완벽 × 해상도)* 아니면 *(방향 틀림 × 배율 하나)* 다.
> **실제 모델은 둘 다 틀린다.**

```
              k=1     k=2     k=4     k=8       (k = 몇 배로 뭉갰나. 작을수록 선명)
  α=1.00     −0.071  −0.038  −0.017  −0.004    ← 이 행만 쟀다 (방향이 완벽할 때)
  α=0.75       ?       ?       ?       ?
  α=0.50       ?       ?       ?       ?
  α=0.35       ?       ?       ?       ?       ← **우리 모델이 서 있는 행. 통째로 비어 있다**
  α=0.25       ?       ?       ?       ?
  α=0.00     +0.051    ?       ?       ?       ← 이 열만 쟀다 (방향이 틀렸을 때)
```

**설계 결정은 가운데에 달려 있는데 거기가 비어 있었다.**

그리고 **틀리는 방식을 두 가지로 나눠** 쟀다. 이게 핵심이었다.

```
  A-1  방향이 섞임    static + blur_k( α·자기잔차 + (1−α)·남의잔차 )
  A-2  세기만 약함    static + blur_k( α·자기잔차 )
```

**A-2 를 넣은 이유**: 결정론 회귀의 가장 그럴듯한 실패 모드다.
L1/L2 로 학습하면 조건부 평균을 찍게 되고, **그 평균은 실제 움직임보다 작다.**
즉 "틀린 방향"이 아니라 "맞는 방향인데 소심함"일 공산이 크다.

**판정선은 측정 전에 018 §9-c 에 고정했고, 스크립트가 기계적으로 적용했다.**

## ⭐ 결과 — 두 실패 모드가 **정반대로 행동한다** (n=96, ΔDV, 음수여야 이득)

```
  A-1  방향이 섞임                        A-2  방향은 맞고 세기만 약함
  α \ k    1       2       4       8       α \ k    1       2       4       8
  1.00  −0.064  −0.031  −0.010  +0.001     1.00  −0.064  −0.031  −0.010  +0.001
  0.75  −0.009  −0.000  +0.004  +0.008     0.75  −0.042  −0.021  −0.010  −0.001
  0.50  +0.030  +0.018  +0.016  +0.014     0.50  −0.020  −0.014  −0.009  −0.002
  0.35  +0.042  +0.026  +0.022  +0.017     0.35  −0.013  −0.011  −0.007  −0.002
  0.25  +0.046  +0.031  +0.026  +0.019     0.25  −0.010  −0.008  −0.005  −0.002
  0.00  +0.053  +0.039  +0.033  +0.024     0.00    0       0       0       0
        ▲ 전부 양수 = 전부 손해                   ▲ 전부 음수 = 전부 이득
        ▲ 해상도를 올리면 **더 나빠진다**            ▲ 해상도를 올리면 더 좋아진다
```

**같은 α, 같은 k 인데 부호가 반대다.**
차이는 하나뿐 — **틀린 성분이 "남의 움직임"인가, 아니면 "그냥 작음"인가.**

```
  방향이 섞이면  →  해상도는 **틀린 움직임을 더 선명하게 그리는 도구**가 된다. 올릴수록 손해
  방향이 맞으면  →  해상도는 **맞는 움직임을 더 정확히 그리는 도구**가 된다. 올릴수록 이득
```

> **⇒ 해상도는 1순위 설계 변수가 아니다. 방향 정확도의 *증폭기* 다.**
> [002](./002-residual_headroom.md) 와 018 §3.7⑤ 에서 "해상도가 곧 이득이다"라고 쓴 것은
> **α=1 행(방향이 완벽할 때)만 보고 한 말이었다.**

## 사전 등록한 판정선의 기계적 적용 결과

```
  A-1 → H1(해상도 우선) **강등**.
        α=0.35 에서 k 를 4→2 로 올리면 오히려 나빠진다(+0.00447, t=+5.10)
  A-1 → ⚠ **α=0.35 행이 전 k 에서 static 보다 나쁘다 → 잔차 노선 자체를 재검토하라**
  A-2 → **노선이 '소심함'에 강건하다.** α_min = 0.25 — 세기를 25% 만 맞혀도 이득이 남는다
```

## 우리 확산모델의 좌표가 갱신됐다 — 그리고 나쁜 쪽이다

```
  016 §9.2:  로컬에서 우리 모델은 static 대비 +0.02073
  A-1 격자의 k=1 열에서 그 값에 가장 가까운 칸:  **α ≈ 0.5** (차이 0.00047)
```

**우리 확산모델은 "절반은 맞는 방향, 절반은 남의 움직임"이다.**
016 이 "남의 잔차 35% 세기"라 부른 것을 더 정확히 말하면 **"방향이 절반쯤 섞여 있다"** 이고,
그건 A-1 쪽 실패 모드다. 그래서 A-1 격자에서 그 행은 **전 k 에서 손해**다.

[005](./005-ksample_closed.md) 에서 샘플 평균이 채점을 악화시킨 것과 앞뒤가 맞는다 —
**섞인 방향을 평균내도 섞임이 사라지지 않고 흐림만 늘어난다.**

## 판정선이 "잔차 노선을 재검토하라"고 했다 — 재검토 결과

**노선을 접지 않는다. 다만 근거가 바뀐다.**

| | 근거 |
|---|---|
| 옛 근거 | "잔차의 헤드룸이 크다" ← **α=1 행의 이야기였다** |
| **새 근거** | "A-2 쪽에 떨어지기만 하면 **25% 세기로도 이긴다** — 매우 관대하다" |
| | 그리고 **결정론 회귀는 구조적으로 A-2 쪽을 향한다** |

**왜 A-2 쪽을 향하나**: 결정론 회귀는 같은 입력에 항상 같은 답을 낸다.
확산모델이 A-1 쪽인 이유는 **매번 다른 표본을 뽑기 때문**이고, 결정론 회귀에는 그 성질이 없다.
조건부 평균은 **방향을 무작위로 바꾸지 않고 세기를 줄인다.**

**⚠ 경계**: 이건 이론적 기대이지 측정이 아니다.
그리고 [005](./005-ksample_closed.md) 는 "조건부 평균이 채점에서 벌받는다"는
**반대 방향 증거**를 준다. **둘을 화해시키는 유일한 길은 실제로 학습해 보는 것이다.**

그리고 016 §9.2-c 의 하방 봉쇄(잔차 헤드 zero-init → 출력이 정확히 static)는 그대로 유효하다.

> **⇒ C 설계서의 1순위 질문**
> ~~"해상도를 어떻게 확보하나"~~ → **"방향을 어떻게 맞히나"**
